릴레이는 코일에 전류를 흘리면 전자석이 접점을 움직여 다른 회로를 켜고 끄는 부품입니다. 실제 금속 접점이 붙었다 떨어지기 때문에 동작 원리를 눈으로 확인하기도 쉽습니다.

그렇다면 물리적으로 움직이는 부품 없이 전기를 이용해 다른 전류를 켜고 끌 수는 없을까요?

그 역할을 하는 대표적인 전자부품이 **트랜지스터(Transistor)**입니다.

트랜지스터는 작은 전기 신호를 이용하여 더 큰 전류를 제어할 수 있는 **반도체 소자**입니다. 스위치뿐 아니라 신호를 증폭하는 데도 사용할 수 있으며, 현대의 컴퓨터, 스마트폰, 자동차 전자장치, 전원공급장치 등 거의 모든 전자기기의 핵심 부품입니다.

이 글에서는 여러 종류의 트랜지스터 가운데 동작 원리를 이해하기 쉬운 **BJT(Bipolar Junction Transistor)**를 중심으로 설명하고 마지막에 MOSFET과 어떤 차이가 있는지 살펴봅니다.

## 먼저 트랜지스터를 한눈에 보기

| 구분           | 내용                          |
| ------------ | --------------------------- |
| 정식 명칭        | Transistor                  |
| 대표적인 종류      | BJT, MOSFET                 |
| 주요 기능        | 스위칭, 증폭                     |
| 기계적 움직임      | 없음                          |
| BJT 제어 방법    | 베이스 전류                      |
| MOSFET 제어 방법 | 게이트 전압                      |
| 주요 사용처       | 전원 제어, 모터 제어, 증폭기, 디지털 회로 등 |

트랜지스터를 처음 이해할 때는 **전기로 작동하는 초고속 스위치**라고 생각하면 쉽습니다.

하지만 일반적인 스위치와 결정적인 차이가 있습니다.

일반 스위치는 사람이 직접 접점을 붙이지만 트랜지스터는 **반도체 내부의 전류 흐름을 전기적으로 제어합니다.**

## 릴레이와 비교하면 이해하기 쉽다

릴레이는 작은 전기 신호로 큰 전류를 제어할 수 있습니다.

```text
제어 회로
   │
   ↓
[ 릴레이 코일 ]

     ↓ 전자석이 움직임

전원 ── 접점 ── 모터
```

코일에 전류가 흐르면 전자석이 접점을 물리적으로 움직입니다.

접점이 붙으면 모터에 전류가 흐르고 접점이 떨어지면 전류가 끊깁니다.

트랜지스터 역시 결과적으로 비슷한 일을 할 수 있습니다.

```text
작은 전기 신호
       │
       ↓
 [ 트랜지스터 ]
       │
       ↓
   큰 전류 제어
       │
      모터
```

하지만 내부에서 움직이는 접점이 없습니다.

**반도체의 전기적 특성을 이용하여 전류가 흐르는 정도를 제어합니다.**

따라서 릴레이보다 훨씬 빠르게 동작할 수 있고 기계적인 접점 마모도 없습니다.

## 1. BJT 트랜지스터에는 세 개의 단자가 있다

대표적인 BJT 트랜지스터에는 세 개의 단자가 있습니다.

* Base(B): 베이스
* Collector(C): 컬렉터
* Emitter(E): 이미터

NPN 트랜지스터를 단순화하면 다음과 같이 생각할 수 있습니다.

```text
            Collector(C)
                 │
                 │
                 ↓
Base(B) ─── [ Transistor ]
                 │
                 ↓
             Emitter(E)
```

베이스는 트랜지스터를 **제어하는 단자**입니다.

컬렉터와 이미터는 주로 **제어되는 전류가 흐르는 경로**입니다.

NPN 트랜지스터를 스위치로 사용할 때는 베이스에 적절한 전류를 흘려주면 컬렉터와 이미터 사이에 훨씬 큰 전류가 흐를 수 있습니다.

즉 핵심적인 관계는 다음과 같습니다.

**작은 베이스 전류 → 큰 컬렉터 전류 제어**

여기서 중요한 것은 베이스 전류 자체가 컬렉터 전류로 그대로 커지는 것이 아니라, 베이스의 상태가 트랜지스터 내부의 전하 흐름을 제어한다는 것입니다.

## 2. 왜 작은 전류로 큰 전류를 제어할 수 있을까?

BJT는 반도체를 이용해 만들어집니다.

대표적인 NPN 트랜지스터는 이름 그대로 다음과 같은 구조를 가집니다.

```text
N형        P형        N형

Emitter    Base     Collector
   │         │          │
   └─────────┴──────────┘

        N - P - N
```

여기서 N형과 P형은 서로 다른 특성을 갖도록 불순물을 첨가한 반도체입니다.

N형에는 전도에 참여할 수 있는 전자가 상대적으로 많고, P형에서는 전자가 비어 있는 상태인 **정공(hole)**을 주요 운반자로 설명합니다.

N형과 P형을 붙이면 경계 부분에 **PN 접합**이 만들어집니다.

BJT는 이 PN 접합을 두 개 이용하여 베이스에 작은 전류를 공급했을 때 이미터에서 공급된 전하 운반자의 상당 부분이 매우 얇은 베이스 영역을 지나 컬렉터 쪽으로 이동하도록 만들어진 소자입니다.

그래서 작은 베이스 전류의 변화로 훨씬 큰 컬렉터 전류를 제어할 수 있습니다.

단순하게 표현하면 다음과 같습니다.

```text
베이스 전류 없음

Collector
    │
    X
    │
Emitter

→ 거의 전류가 흐르지 않음
```

베이스에 전류를 공급하면,

```text
베이스 전류
    ↓

Collector
    │
    │
    │
Emitter

→ Collector-Emitter 경로로
   큰 전류가 흐를 수 있음
```

실제 내부에서는 스위치처럼 금속 접점이 연결되는 것이 아닙니다.

**반도체 내부의 전하 운반자 움직임이 달라지는 것입니다.**

## 3. NPN 트랜지스터를 실제 스위치처럼 사용해보자

예를 들어 5V 제어 신호를 이용해 모터를 켜고 싶다고 생각해봅시다.

```text
             +12V
               │
             [모터]
               │
               │
           Collector
               │
            [ NPN ]
               │
            Emitter
               │
              GND

5V 제어 ── 저항 ── Base
```

제어 신호가 없으면 베이스 전류가 흐르지 않습니다.

```text
Base OFF

5V 제어 = 0V

        모터
         │
         X
         │
     트랜지스터

→ 모터 OFF
```

베이스에 적절한 전류가 흐르면 트랜지스터가 켜집니다.

```text
Base ON

5V 제어
   │
   ↓
  Base

12V
 │
모터
 │
 ↓
Collector
 │
트랜지스터
 │
Emitter
 │
GND

→ 모터 ON
```

이런 방식으로 마이크로컨트롤러 같은 작은 제어 회로가 직접 감당하기 어려운 전류를 사용하는 장치를 제어할 수 있습니다.

## 4. 베이스에 왜 저항을 연결할까?

앞의 회로에서 5V 신호와 베이스 사이에 저항이 들어갔습니다.

```text
5V ── [저항] ── Base
```

이 저항은 매우 중요합니다.

실리콘 NPN 트랜지스터의 베이스-이미터 접합은 순방향으로 동작할 때 다이오드와 비슷한 특성을 보입니다.

보통 동작 상태에서 베이스-이미터 전압 `VBE`가 약 0.6~0.7V 정도가 되는 경우가 많지만, 정확한 값은 트랜지스터 종류, 전류와 온도에 따라 달라집니다.

베이스를 5V 출력에 저항 없이 직접 연결하면 베이스 전류를 충분히 제한하지 못할 수 있습니다.

그래서 저항을 넣어 전류를 제한합니다.

예를 들어 단순한 계산을 위해 다음과 같이 가정해봅시다.

* 제어 전압: 5V
* VBE: 0.7V
* 베이스 저항: 1kΩ

저항에 걸리는 전압은 대략 다음과 같습니다.

**5V - 0.7V = 4.3V**

옴의 법칙을 적용하면,

**I = V / R**

**I = 4.3 / 1,000 = 0.0043A**

따라서 베이스 전류는 약 **4.3mA**입니다.

실제 회로를 설계할 때는 이 계산만으로 저항을 결정하지 않고 트랜지스터의 데이터시트와 필요한 컬렉터 전류, 제어회로가 공급할 수 있는 전류 등을 함께 확인해야 합니다.

## 5. 트랜지스터는 단순한 ON/OFF 스위치만은 아니다

트랜지스터의 중요한 특징은 완전히 켜거나 끄는 것뿐 아니라 **중간 상태를 이용할 수 있다는 것**입니다.

BJT의 동작 영역을 크게 나누면 다음과 같이 생각할 수 있습니다.

| 상태             | 의미                    | 스위치로 생각하면 |
| -------------- | --------------------- | --------- |
| 차단(Cutoff)     | 컬렉터 전류가 거의 흐르지 않음     | OFF       |
| 활성(Active)     | 베이스 입력에 따라 컬렉터 전류가 변함 | 증폭 영역     |
| 포화(Saturation) | 스위치로서 충분히 켜진 상태       | ON        |

따라서 트랜지스터는 스위치뿐 아니라 **증폭기**로도 사용할 수 있습니다.

## 6. 트랜지스터가 신호를 증폭한다는 것은 무슨 뜻일까?

마이크에서 아주 작은 전기 신호가 나온다고 생각해봅시다.

```text
마이크
  │
  │ 작은 신호
  ↓
트랜지스터
  │
  │ 더 큰 신호
  ↓
스피커 쪽 회로
```

여기서 오해하기 쉬운 부분이 있습니다.

**트랜지스터가 아무것도 없는 상태에서 에너지를 만들어내는 것은 아닙니다.**

실제 에너지는 전원에서 공급됩니다.

```text
             전원
              │
              ↓
작은 신호 → 트랜지스터 → 큰 출력 신호
```

입력 신호가 트랜지스터를 제어하고 트랜지스터가 **전원에서 부하로 전달되는 에너지의 양을 조절**하는 것입니다.

수도꼭지를 생각하면 이해하기 쉽습니다.

사람이 손으로 수도꼭지를 조금 움직이는 힘 자체가 물을 만들어내는 것은 아닙니다.

```text
수도관 압력
     │
     ↓
 [ 수도꼭지 ] ← 작은 손의 움직임
     │
     ↓
  많은 물
```

마찬가지로 트랜지스터의 작은 입력 신호는 큰 출력에 필요한 에너지를 직접 공급하는 것이 아니라 **전원으로부터 전달되는 에너지를 제어**합니다.

## 7. 전류 증폭률 β(hFE)는 무엇일까?

BJT에서는 흔히 다음과 같은 관계를 볼 수 있습니다.

**IC ≈ β × IB**

* IC: 컬렉터 전류
* IB: 베이스 전류
* β: 전류 증폭률

β는 데이터시트에서 `hFE`라고 표시되기도 합니다.

예를 들어 특정 동작 조건에서 β가 100이라고 단순하게 가정하면,

```text
베이스 전류 = 1mA

        ↓

컬렉터 전류 ≈ 100mA
```

처럼 생각할 수 있습니다.

하지만 **β는 정확하게 고정된 값이 아닙니다.**

같은 제품이라도 개체에 따라 다를 수 있고 컬렉터 전류, 온도, 전압 등에 따라서도 변합니다.

특히 BJT를 ON/OFF 스위치로 사용할 때는 단순히 `IC = βIB`만 믿고 설계하지 않습니다. 트랜지스터가 충분히 포화되도록 필요한 베이스 구동 조건을 데이터시트를 기준으로 결정해야 합니다.

## 8. 트랜지스터가 켜져 있어도 전압이 완전히 0V가 되지는 않는다

이상적인 스위치라면 ON 상태의 저항이 0Ω이고 전압 강하도 0V라고 생각할 수 있습니다.

실제 BJT는 그렇지 않습니다.

포화 상태의 BJT에서는 컬렉터와 이미터 사이에 작은 전압이 남습니다.

이를 **VCE(sat)**라고 합니다.

```text
이상적인 스위치 ON

Collector ───────── Emitter
전압강하 = 0V


실제 BJT ON

Collector ──[ BJT ]── Emitter
             ↓
        약간의 전압강하
```

예를 들어 컬렉터 전류가 1A이고 트랜지스터의 실제 `VCE(sat)`가 0.2V라면 트랜지스터에서 발생하는 전력 손실은 단순화하여

**P = V × I**

**P = 0.2 × 1 = 0.2W**

가 됩니다.

이 전력은 주로 열로 변합니다.

따라서 큰 전류를 제어하는 트랜지스터에서는 발열과 방열도 중요합니다.

## 9. NPN과 PNP는 무엇이 다를까?

BJT에는 대표적으로 **NPN과 PNP**가 있습니다.

구조는 다음과 같습니다.

```text
NPN

N - P - N


PNP

P - N - P
```

둘은 전압과 전류의 극성이 반대 방향으로 동작합니다.

초보자가 스위칭 회로를 배울 때는 일반적으로 NPN부터 접하게 됩니다.

NPN을 이용한 대표적인 로우사이드 스위칭은 다음과 같습니다.

```text
+12V
  │
 [부하]
  │
 [NPN]
  │
 GND
```

트랜지스터가 부하와 GND 사이에 있습니다.

반대로 PNP를 이용하면 전원 쪽을 스위칭하는 구성을 만들 수 있습니다.

```text
+12V
  │
 [PNP]
  │
 [부하]
  │
 GND
```

다만 실제 회로에서는 필요한 전압, 전류, 구동 방식에 따라 여러 구성이 사용됩니다.

## 10. 모터를 트랜지스터로 제어할 때 주의할 점

모터는 단순한 저항과 다릅니다.

모터 내부에는 코일이 있기 때문에 전류를 갑자기 끊으면 순간적으로 큰 전압이 발생할 수 있습니다.

```text
전원
 │
모터
 │
트랜지스터
 │
GND
```

트랜지스터가 ON 상태일 때 모터에 전류가 흐르다가 갑자기 OFF하면 코일은 흐르던 전류를 계속 유지하려는 성질을 보입니다.

그 결과 트랜지스터가 견딜 수 있는 전압보다 높은 순간적인 전압이 발생하여 트랜지스터가 손상될 수 있습니다.

그래서 DC 모터나 릴레이 코일 같은 유도성 부하에는 흔히 **플라이백 다이오드(Flyback Diode)**를 사용합니다.

```text
       +V
        │
        ├──────┐
        │      │
      [모터]  [다이오드]
        │      │
        ├──────┘
        │
   [트랜지스터]
        │
       GND
```

다이오드는 평상시에는 동작에 영향을 거의 주지 않지만 트랜지스터가 꺼질 때 코일 전류가 흐를 수 있는 경로를 제공하여 큰 역전압으로부터 트랜지스터를 보호합니다.

## 11. 그런데 왜 요즘은 MOSFET을 많이 사용할까?

모터나 큰 전류를 ON/OFF하는 용도에서는 BJT 대신 **MOSFET**을 많이 사용합니다.

MOSFET도 트랜지스터의 한 종류입니다.

정식 명칭은 **Metal-Oxide-Semiconductor Field-Effect Transistor**입니다.

BJT와 MOSFET은 단자 이름부터 다릅니다.

| BJT       | MOSFET |
| --------- | ------ |
| Base      | Gate   |
| Collector | Drain  |
| Emitter   | Source |

가장 중요한 차이는 **제어 방법**입니다.

BJT는 기본적으로 베이스에 **전류를 공급하여** 제어합니다.

MOSFET은 Gate와 Source 사이의 **전압으로** 채널의 전도 상태를 제어합니다.

```text
BJT

Base 전류
    ↓
Collector ── Emitter 전류 제어


MOSFET

Gate 전압
    ↓
Drain ── Source 전류 제어
```

MOSFET의 게이트는 절연층 때문에 정상적인 DC 상태에서는 매우 작은 전류만 필요합니다.

다만 게이트는 전기적으로 **커패시터와 비슷한 성질**을 가지고 있기 때문에 켜고 끌 때는 게이트를 충전하고 방전하기 위한 전류가 필요합니다.

따라서 "MOSFET의 게이트에는 전류가 전혀 흐르지 않는다"라고 이해하는 것은 정확하지 않습니다.

## 12. MOSFET은 어떻게 전류를 흐르게 할까?

대표적인 N채널 Enhancement MOSFET을 생각해봅시다.

단자는 다음과 같습니다.

```text
          Drain
            │
            │
        [ MOSFET ]
            │
            │
          Source

Gate ───────┤
```

Gate와 Source 사이 전압을 **VGS**라고 합니다.

VGS가 낮으면 Drain과 Source 사이의 전류가 거의 흐르지 않습니다.

```text
Gate = LOW

Drain
  │
  X
  │
Source
```

Gate 전압을 충분히 높이면 전기장에 의해 반도체 표면에 전류가 흐를 수 있는 **채널(Channel)**이 형성됩니다.

```text
Gate = HIGH

Drain
  │
  │
  │
Source
```

여기에서도 실제 금속 접점이 붙는 것은 아닙니다.

**전기장이 반도체 내부의 전하 분포를 바꾸어 전류가 흐를 수 있는 통로를 만드는 것입니다.**

이것이 MOSFET의 핵심적인 원리입니다.

## 13. MOSFET의 Threshold Voltage를 주의해야 한다

MOSFET 데이터시트를 보면 **VGS(th)**라는 값이 있습니다.

이를 Gate Threshold Voltage라고 합니다.

처음 보면

> VGS(th)가 2V니까 게이트에 2V만 주면 MOSFET이 완전히 켜지는구나.

라고 생각하기 쉽습니다.

하지만 그렇지 않습니다.

VGS(th)는 일반적으로 **Drain 전류가 아주 조금 흐르기 시작하는 조건**을 나타냅니다.

MOSFET이 큰 전류를 낮은 저항으로 흘릴 수 있는 완전한 ON 상태가 된다는 뜻이 아닙니다.

큰 전류를 스위칭하려면 데이터시트에서 실제 사용할 Gate 전압에서의 **RDS(on)** 등을 확인해야 합니다.

특히 3.3V나 5V 마이크로컨트롤러로 직접 구동할 경우에는 낮은 Gate 전압에서도 충분히 켜질 수 있도록 설계된 **Logic-Level MOSFET**인지 확인하는 것이 중요합니다.

## 14. RDS(on)은 무엇일까?

MOSFET이 충분히 켜졌을 때 Drain과 Source 사이도 완벽한 0Ω은 아닙니다.

작은 저항이 존재합니다.

이 값을 **RDS(on)**이라고 합니다.

예를 들어,

* RDS(on) = 0.01Ω
* 전류 = 10A

라고 가정하면 MOSFET에서 발생하는 전도 손실은

**P = I² × R**

이므로,

**P = 10² × 0.01 = 1W**

입니다.

그런데 전류가 20A가 되면,

**P = 20² × 0.01 = 4W**

가 됩니다.

전류는 두 배가 되었지만 손실은 네 배가 되었습니다.

따라서 고전류 회로에서는 MOSFET의 RDS(on)이 매우 중요합니다.

## 15. RC카 ESC에도 MOSFET이 들어간다

MOSFET의 실제 사용 사례를 보기 좋은 장치가 **RC카 ESC(Electronic Speed Controller)**입니다.

브러시드 모터의 아주 단순한 예를 생각하면,

```text
배터리
  │
  ↓
MOSFET
  │
  ↓
모터
  │
 GND
```

처럼 MOSFET을 이용해 모터 전류를 제어할 수 있습니다.

그런데 ESC는 단순히 MOSFET을 한 번 켜고 계속 유지하는 것만 하지 않습니다.

매우 빠른 속도로 ON/OFF를 반복합니다.

```text
ON    OFF    ON    OFF

████______████______████
```

이런 방식의 대표적인 제어 방법이 **PWM(Pulse Width Modulation)**입니다.

한 주기에서 켜져 있는 시간의 비율을 **듀티비(Duty Cycle)**라고 합니다.

예를 들어,

```text
25%

██______██______██______


50%

████____████____████____


75%

██████__██████__██████__
```

처럼 ON 시간을 변화시키면 모터에 전달되는 평균적인 전압·전력이 달라집니다.

그래서 RC 송신기의 스로틀을 조금 당겼을 때와 끝까지 당겼을 때 모터 속도를 다르게 만들 수 있습니다.

## 16. 브러시리스 ESC는 MOSFET을 어떻게 사용할까?

브러시리스 모터는 일반적인 DC 브러시드 모터보다 제어가 복잡합니다.

보통 세 개의 모터 선이 있습니다.

```text
ESC ── U ──┐
     ── V ──┼── BLDC Motor
     ── W ──┘
```

ESC는 MOSFET들을 조합한 **3상 인버터 회로**를 사용해 U, V, W 각 상에 흐르는 전류를 순서와 타이밍에 맞게 제어합니다.

단순화하면,

```text
        Battery +

       MOSFET
          │
U ────────┤
       MOSFET
          │
         GND


       MOSFET
          │
V ────────┤
       MOSFET
          │
         GND


       MOSFET
          │
W ────────┤
       MOSFET
          │
         GND
```

처럼 각 상에 위쪽과 아래쪽 MOSFET이 배치됩니다.

이를 **하프 브리지(Half Bridge)** 세 개로 구성된 3상 인버터라고 볼 수 있습니다.

ESC는 이 MOSFET들을 매우 빠르고 정확한 순서로 켜고 끄면서 브러시리스 모터를 회전시킵니다.

따라서 고성능 ESC에서는 MOSFET의 성능과 개수, RDS(on), 스위칭 손실, 게이트 드라이버, PCB 설계와 방열 구조 등이 중요합니다.

## 17. 릴레이, BJT, MOSFET을 비교하면

| 특징          | 릴레이           | BJT       | MOSFET    |
| ----------- | ------------- | --------- | --------- |
| 기본 역할       | 스위치           | 스위치·증폭    | 스위치·증폭    |
| 제어 방법       | 코일 전류         | 베이스 전류    | 게이트 전압    |
| 물리적 접점      | 있음            | 없음        | 없음        |
| 동작 속도       | 느림            | 빠름        | 매우 빠름     |
| 접점 마모       | 있음            | 없음        | 없음        |
| 제어측과 부하측 절연 | 가능            | 기본적으로 안 됨 | 기본적으로 안 됨 |
| 빠른 PWM      | 부적합           | 가능        | 매우 적합     |
| 고전류 모터 제어   | 가능하지만 느림      | 가능        | 매우 많이 사용  |
| 신호 증폭       | 일반적으로 사용하지 않음 | 매우 적합     | 가능        |

릴레이와 트랜지스터가 모두 전기적으로 스위칭할 수 있다고 해서 완전히 같은 부품은 아닙니다.

특히 릴레이는 **제어 회로와 접점 회로가 물리적으로 분리되어 전기적 절연을 쉽게 얻을 수 있다는 장점**이 있습니다.

BJT와 MOSFET은 기본적인 회로에서는 제어측과 출력측이 전기적으로 연결되어 있습니다.

절연이 필요하면 옵토커플러, 절연 게이트 드라이버, 트랜스포머 등의 별도 방법을 사용할 수 있습니다.

## 18. 트랜지스터가 컴퓨터의 핵심이라는 것은 무슨 뜻일까?

트랜지스터를 매우 작게 만들면 단순한 ON/OFF 상태를 디지털 정보로 사용할 수 있습니다.

```text
OFF → 0
ON  → 1
```

여러 트랜지스터를 조합하면 논리 게이트를 만들 수 있습니다.

예를 들어,

```text
트랜지스터
    ↓
논리 게이트
    ↓
가산기 / 레지스터
    ↓
CPU
```

와 같이 더 복잡한 회로를 구성할 수 있습니다.

현대 CPU와 GPU에는 수십억 개 이상의 트랜지스터가 집적됩니다.

여기서 사용되는 트랜지스터는 일반적인 개별 BJT가 아니라 주로 MOSFET 계열의 미세한 트랜지스터입니다.

즉 우리가 컴퓨터에서 수행하는 덧셈, 프로그램 실행, 그래픽 처리 등의 가장 아래 단계에는 결국 **수많은 트랜지스터의 전기적 상태 변화**가 있습니다.

## 자주 헷갈리는 내용을 정리하면

| 오해                           | 바르게 이해하기                                        |
| ---------------------------- | ----------------------------------------------- |
| 트랜지스터 안에서도 스위치 접점이 붙는다       | 기계적인 접점이 없으며 반도체 내부의 전하 흐름을 제어함                 |
| 작은 전류가 그대로 큰 전류로 변한다         | 작은 입력이 전원에서 부하로 흐르는 큰 전류를 제어함                   |
| 트랜지스터가 에너지를 증폭해서 만들어낸다       | 출력 에너지는 전원에서 공급됨                                |
| BJT의 β는 항상 일정하다              | 전류, 온도, 개체 등에 따라 크게 달라질 수 있음                    |
| 베이스에 전압만 주면 된다               | BJT는 베이스 전류를 적절하게 제한하고 공급해야 함                   |
| MOSFET Gate에는 항상 전류가 0이다     | 정상 DC 상태에서는 매우 작지만 스위칭 시 게이트 충·방전 전류가 필요함       |
| VGS(th)를 넘으면 MOSFET이 완전히 켜진다 | VGS(th)는 보통 소량의 전류가 흐르기 시작하는 기준이며 충분한 ON 상태와 다름 |
| MOSFET이 ON이면 저항이 0Ω이다        | 실제로는 RDS(on)이 존재하여 전력 손실과 발열이 발생함               |
| 릴레이보다 MOSFET이 항상 좋다          | 전기적 절연, AC/DC, 전압·전류, 속도 등 용도에 따라 적합한 부품이 다름    |

## 핵심만 다시 정리하면

트랜지스터는 **작은 전기 신호로 더 큰 전류의 흐름을 제어하는 반도체 소자**입니다.

BJT에서는 주로 **베이스 전류로 컬렉터 전류를 제어**하고, MOSFET에서는 **게이트-소스 전압으로 드레인-소스 사이의 전도 상태를 제어**합니다.

릴레이와 가장 큰 차이는 물리적으로 움직이는 접점이 없다는 것입니다.

```text
릴레이
전류 → 전자석 → 접점 움직임 → 전류 ON/OFF


BJT
베이스 전류 → 반도체 내부 상태 변화 → 컬렉터 전류 제어


MOSFET
게이트 전압 → 전기장 → 채널 형성 → 드레인 전류 제어
```

이 차이 때문에 트랜지스터는 릴레이보다 훨씬 빠르게 동작할 수 있습니다.

그리고 MOSFET을 빠르게 ON/OFF하면 PWM으로 모터의 출력을 조절할 수 있고, 여러 MOSFET을 조합하면 브러시리스 모터를 구동하는 ESC 같은 장치도 만들 수 있습니다.

결국 **릴레이 → 다이오드 → BJT → MOSFET → PWM → ESC**의 원리를 차례로 이해하면 RC카 ESC 같은 전자장치가 단순한 검은 상자가 아니라 각각의 전자부품이 어떤 역할을 하는지 회로 수준에서 이해되기 시작합니다.
