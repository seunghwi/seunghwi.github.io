저항(Resistor)은 전자회로에서 가장 기본적이고 많이 사용되는 부품 가운데 하나입니다.

겉으로 보면 작은 막대나 칩 형태에 불과하지만 실제 회로에서는 매우 다양한 역할을 합니다.

가장 대표적인 역할은 **전류가 너무 많이 흐르지 않도록 제한하는 것**입니다.

하지만 저항은 단순히 전류를 줄이는 용도로만 사용되지 않습니다.

* 전압을 나누기
* LED 전류 제한
* 트랜지스터 베이스 전류 제한
* MOSFET Gate 안정화
* 센서 회로
* 전류 측정
* 신호 레벨 설정
* 풀업/풀다운

등 거의 모든 전자회로에서 사용됩니다.

이 글에서는 저항이 왜 전류를 제한하는지부터 시작해 옴의 법칙, 발열, 직렬·병렬 연결, 분압 회로와 실제 부품 선택 기준까지 살펴봅니다.

## 먼저 저항을 한눈에 보기

| 항목    | 내용                      |
| ----- | ----------------------- |
| 정식 명칭 | Resistor                |
| 기본 역할 | 전류 제한                   |
| 물리량   | 저항 R                    |
| 단위    | 옴(Ω)                    |
| 대표 공식 | V = I × R               |
| 전력 손실 | P = I²R 또는 V²/R         |
| 주요 용도 | 전류 제한, 분압, 바이어스, 풀업/풀다운 |
| 주요 형태 | 리드형, SMD, 가변저항, 파워저항    |

저항을 처음 이해할 때는 **전류가 흐르기 어렵게 만드는 부품**이라고 생각하면 쉽습니다.

## 1. 저항은 왜 전류를 방해할까?

금속 도선 안에는 전자가 이동할 수 있습니다.

전압을 걸면 전자들은 전기장에 의해 이동하려고 합니다.

하지만 실제 물질 내부에서는 전자가 자유롭게 아무 방해 없이 이동하는 것이 아닙니다.

```text
전기장
  ↓
전자 이동
  ↓
원자와 충돌
  ↓
이동 방해
```

이처럼 전하의 이동을 방해하는 정도를 **저항(Resistance)**이라고 합니다.

저항이 클수록 같은 전압에서 전류가 적게 흐릅니다.

## 2. 저항의 단위 Ω는 무엇일까?

저항의 단위는 **옴(Ohm)**이며 기호는 `Ω`입니다.

기본 관계는 다음과 같습니다.

**1Ω = 1V / 1A**

즉 1Ω의 저항에 1V를 걸었을 때 1A가 흐른다면 그 저항은 1Ω입니다.

실제 전자회로에서는 다음 단위를 많이 사용합니다.

| 단위  |          값 |
| --- | ---------: |
| 1Ω  |         1Ω |
| 1kΩ |     1,000Ω |
| 1MΩ | 1,000,000Ω |

예를 들어,

```text
100Ω
1kΩ
10kΩ
100kΩ
1MΩ
```

같은 저항값을 자주 볼 수 있습니다.

## 3. 옴의 법칙

전압, 전류, 저항의 관계를 나타내는 가장 중요한 공식이 **옴의 법칙**입니다.

**V = I × R**

입니다.

이를 변형하면,

**I = V / R**

**R = V / I**

가 됩니다.

즉 저항이 일정하다면 전압이 높아질수록 전류가 커지고, 저항이 커질수록 전류는 작아집니다.

## 4. 같은 전압에서 저항이 커지면?

6V 전원에 저항을 연결해봅시다.

### 100Ω

**I = 6 / 100**

**= 0.06A**

즉 **60mA**입니다.

### 1kΩ

**I = 6 / 1000**

**= 0.006A**

즉 **6mA**입니다.

```text
6V + 100Ω
→ 60mA


6V + 1kΩ
→ 6mA
```

저항이 10배 커지면 전류는 10분의 1로 줄었습니다.

## 5. 저항은 전류를 먹는 것일까?

아닙니다.

저항이 전류 일부를 소비해서 뒤쪽으로 적게 보내는 구조가 아닙니다.

직렬 회로에서는 정상 상태에서 저항 앞과 뒤에 흐르는 전류가 같습니다.

```text
전원
 ↓
저항
 ↓
부하

같은 경로라면
전류는 동일
```

저항에서 실제로 변환되는 것은 **전기에너지**입니다.

주로 열로 바뀝니다.

## 6. 저항은 왜 뜨거워질까?

전자가 물질 내부에서 이동하면서 원자들과 상호작용합니다.

이 과정에서 전기에너지가 열에너지로 변합니다.

저항에서 발생하는 전력은,

**P = V × I**

입니다.

옴의 법칙을 적용하면,

**P = I²R**

또는

**P = V² / R**

로 계산할 수 있습니다.

## 7. 전류가 두 배면 발열은 얼마나 증가할까?

같은 저항에서,

**P = I²R**

이므로 전류가 두 배가 되면,

```text
I → 2I

I² → 4I²
```

입니다.

즉 전력 손실은 네 배가 됩니다.

이 관계는 전자회로에서 매우 중요합니다.

## 8. 저항의 와트 정격은 무엇일까?

저항에는 견딜 수 있는 최대 전력이 있습니다.

예를 들어,

```text
1/8W
1/4W
1/2W
1W
5W
10W
```

같이 표시합니다.

예를 들어 1/4W 저항은 약 **0.25W** 수준의 전력을 기준으로 설계된 저항입니다.

정격보다 많은 전력을 지속적으로 소비하면 저항이 과열되어 값이 변하거나 손상될 수 있습니다.

## 9. 저항 전력 계산 예제

12V 전원에 100Ω 저항 하나를 연결했다고 해봅시다.

전류는,

**I = 12 / 100**

**= 0.12A**

입니다.

전력은,

**P = V² / R**

**= 12² / 100**

**= 1.44W**

입니다.

따라서 일반적인 1/4W 저항을 사용하면 크게 과열될 수 있습니다.

이 경우 적절한 여유를 둔 파워저항이 필요합니다.

## 10. 저항값이 크면 발열도 항상 커질까?

아닙니다.

어떤 값이 일정한지에 따라 달라집니다.

### 전류가 일정하다면

**P = I²R**

이므로 저항이 클수록 전력이 커집니다.

### 전압이 일정하다면

**P = V² / R**

이므로 저항이 클수록 전력이 작아집니다.

따라서,

> 저항이 크면 더 뜨겁다.

라고 단순하게 말하면 정확하지 않습니다.

## 11. 실제 저항은 무엇으로 만들까?

저항은 여러 방식으로 만들 수 있습니다.

대표적으로,

* 탄소피막
* 금속피막
* 금속산화물
* 권선
* 후막 SMD

등이 있습니다.

사용하는 재료와 구조에 따라,

* 정밀도
* 온도 안정성
* 노이즈
* 최대 전력
* 고주파 특성

이 달라집니다.

## 12. 탄소피막 저항

탄소 계열 저항막을 이용해 만든 저항입니다.

장점은,

* 저렴함
* 일반 회로에 사용하기 쉬움

입니다.

하지만 금속피막 저항보다 정밀도와 온도 특성이 떨어질 수 있습니다.

## 13. 금속피막 저항

금속막을 이용해 저항값을 만듭니다.

일반적으로,

* 정밀도 좋음
* 온도 안정성 좋음
* 노이즈 적음

이라는 장점이 있습니다.

정확한 아날로그 회로나 측정 회로에서 많이 사용됩니다.

## 14. 권선저항은 무엇일까?

저항선 자체를 감아 만든 저항입니다.

```text
저항선
(((((((((((((
```

큰 전력을 견디기 좋기 때문에 파워저항으로 많이 사용됩니다.

하지만 코일처럼 감겨 있기 때문에 인덕턴스가 생길 수 있습니다.

따라서 고주파 회로에서는 주의가 필요합니다.

## 15. 시멘트 저항은 무엇일까?

큰 전력을 처리하는 저항 중에는 흰색 사각형 형태의 **시멘트 저항**이 흔합니다.

````text
┌──────────┐
│ 10Ω 10W  │
└──────────┘
```

내부 저항체에서 발생하는 열을 견딜 수 있도록 세라믹 계열 재료로 감싸는 형태입니다.

방전기나 전원 회로에서 자주 볼 수 있습니다.

## 16. SMD 저항이란?

현대 전자제품에서는 리드형 저항보다 작은 칩 형태의 저항을 많이 사용합니다.

```text
┌─────┐
│103  │
└─────┘
````

이를 **SMD Resistor**라고 합니다.

PCB 표면에 직접 납땜합니다.

작고 자동 조립에 유리합니다.

## 17. SMD 저항의 103은 무슨 뜻일까?

3자리 표기에서 앞의 두 숫자는 유효숫자이고 마지막 숫자는 뒤에 붙는 0의 개수입니다.

예를 들어,

**103**

은,

```text
10 + 000
= 10,000Ω
= 10kΩ
```

입니다.

**472**

라면,

**47 × 100 = 4,700Ω = 4.7kΩ**

입니다.

## 18. 0Ω 저항은 왜 있을까?

저항값이 0Ω인 부품도 있습니다.

```text
0Ω
```

전류를 제한하는 목적이 아니라 PCB에서 **점퍼선처럼 사용**합니다.

예를 들어 회로 옵션을 선택하거나 자동 조립 과정에서 배선을 연결하기 위해 사용할 수 있습니다.

이상적으로는 0Ω이지만 실제로는 아주 작은 저항이 존재합니다.

## 19. 저항을 직렬로 연결하면?

저항을 한 줄로 연결한 것을 직렬이라고 합니다.

```text
전원 ──[R1]──[R2]── GND
```

전체 저항은 더해집니다.

**R전체 = R1 + R2**

예를 들어,

* R1 = 100Ω
* R2 = 200Ω

이라면,

**R전체 = 300Ω**

입니다.

## 20. 직렬에서는 왜 저항이 더해질까?

전류가 한 개의 경로로 두 저항을 모두 통과해야 합니다.

```text
전류
 ↓
R1에서 방해
 ↓
R2에서 또 방해
```

따라서 전체적인 흐름 방해가 커집니다.

그래서 직렬 저항은 합산됩니다.

## 21. 직렬에서는 전류가 같다

직렬 회로에는 전류가 흐를 경로가 하나뿐입니다.

```text
전원
 ↓
R1
 ↓
R2
 ↓
GND
```

따라서 R1을 흐르는 전류와 R2를 흐르는 전류는 같습니다.

대신 각 저항에 걸리는 전압이 나뉩니다.

## 22. 전압은 저항값에 따라 나뉜다

6V 전원에,

* 100Ω
* 200Ω

저항을 직렬로 연결했다고 해봅시다.

전체 저항은,

**300Ω**

입니다.

전류는,

**I = 6 / 300 = 0.02A**

즉 20mA입니다.

100Ω 저항의 전압은,

**V = 0.02 × 100 = 2V**

200Ω 저항은,

**V = 0.02 × 200 = 4V**

입니다.

```text
6V

── 100Ω ── 200Ω ──

   2V       4V
```

합하면 6V가 됩니다.

## 23. 이것이 전압 분배기다

저항 두 개를 이용하면 입력 전압보다 낮은 전압을 만들 수 있습니다.

```text
Vin
 │
[R1]
 │
 ├── Vout
 │
[R2]
 │
GND
```

이를 **Voltage Divider**, 전압 분배기라고 합니다.

출력 전압은,

**Vout = Vin × R2 / (R1 + R2)**

입니다.

## 24. 분압 계산 예제

Vin이 12V이고,

* R1 = 10kΩ
* R2 = 10kΩ

이라면,

**Vout = 12 × 10 / 20**

**= 6V**

입니다.

```text
12V
 │
10k
 │
 ├── 6V
 │
10k
 │
GND
```

저항이 같으면 전압도 절반으로 나뉩니다.

## 25. 분압기로 12V 전원에서 6V 장치를 구동해도 될까?

대부분의 경우 좋지 않습니다.

분압 회로는 출력에 부하가 거의 없을 때 계산식대로 동작합니다.

6V 장치가 전류를 많이 사용하면 R2와 병렬로 부하가 연결된 것과 같아집니다.

```text
R2
 │
 ├── 부하
 │
GND
```

그러면 실제 출력 전압이 달라집니다.

따라서 전원 변환에는 DC-DC 컨버터나 레귤레이터를 사용하는 것이 일반적입니다.

분압은 주로 **신호 전압을 만드는 데 사용**합니다.

## 26. 저항을 병렬로 연결하면?

병렬 연결은 양 끝을 같은 두 지점에 연결합니다.

```text
      ┌──[R1]──┐
전원 ─┤        ├── GND
      └──[R2]──┘
```

전체 저항은,

**1/R전체 = 1/R1 + 1/R2**

입니다.

두 개라면,

**R전체 = R1 × R2 / (R1 + R2)**

로 계산할 수 있습니다.

## 27. 같은 저항 두 개를 병렬로 연결하면?

100Ω 두 개라면,

**R전체 = 100 × 100 / 200**

**= 50Ω**

입니다.

즉 같은 저항 두 개를 병렬로 연결하면 절반이 됩니다.

```text
100Ω
+
100Ω 병렬

→ 50Ω
```

## 28. 병렬에서는 왜 전체 저항이 작아질까?

전류가 흐를 수 있는 길이 늘어나기 때문입니다.

```text
        ┌── 길 1 ──┐
전류 ───┤          ├──
        └── 길 2 ──┘
```

길이 하나일 때보다 두 개일 때 전류가 더 쉽게 흐를 수 있습니다.

따라서 전체 저항은 더 작아집니다.

## 29. 병렬에서는 전압이 같다

병렬로 연결된 각 저항의 양단은 동일한 두 지점에 연결되어 있습니다.

따라서 각 저항에 걸리는 전압은 같습니다.

```text
      ┌── R1 ──┐
6V ───┤        ├── 0V
      └── R2 ──┘
```

R1과 R2 모두 6V가 걸립니다.

대신 전류가 나뉩니다.

## 30. LED에 저항을 사용하는 이유

LED는 전압을 조금만 높여도 전류가 급격하게 증가할 수 있습니다.

따라서 전류 제한이 필요합니다.

```text
5V
 │
[R]
 │
LED
 │
GND
```

저항이 전류를 제한합니다.

## 31. LED 저항 계산

예를 들어,

* 전원 5V
* LED 순방향 전압 2V
* 원하는 전류 10mA

라고 해봅시다.

저항에 걸리는 전압은,

**5 - 2 = 3V**

입니다.

필요 저항은,

**R = V / I**

**= 3 / 0.01**

**= 300Ω**

입니다.

따라서 약 300Ω의 저항을 사용할 수 있습니다.

## 32. 저항 없이 LED를 연결하면?

전원과 LED 내부 저항에 의해서만 전류가 제한됩니다.

LED는 전류가 과도하게 증가할 수 있습니다.

```text
전류 급증
 ↓
LED 발열
 ↓
손상
```

그래서 일반적인 전압원 구동에서는 전류 제한 장치가 필요합니다.

## 33. BJT 베이스에도 저항을 넣는다

BJT의 Base-Emitter 접합도 다이오드와 비슷한 특성을 가집니다.

```text
MCU ──[R]── Base
```

저항 없이 연결하면 마이크로컨트롤러에서 너무 큰 전류가 흐를 수 있습니다.

그래서 Base 전류를 제한합니다.

## 34. MOSFET Gate 저항은 조금 다른 역할이다

MOSFET Gate는 정상 DC 상태에서는 전류가 거의 필요하지 않습니다.

하지만 Gate가 커패시터처럼 동작하기 때문에 ON/OFF 순간에는 충·방전 전류가 필요합니다.

```text
Driver ──[R]── Gate
```

이 저항은,

- Gate 충전 전류 제한
- 스위칭 속도 조절
- 링잉 감소
- EMI 감소

등을 위해 사용합니다.

즉 BJT Base 저항과 목적이 완전히 같지는 않습니다.

## 35. 풀업 저항은 무엇일까?

디지털 입력 핀이 아무것에도 연결되지 않으면 전압이 불확실해질 수 있습니다.

이를 **Floating** 상태라고 합니다.

```text
입력핀 ─── 아무것도 없음
```

주변 노이즈 때문에 HIGH와 LOW가 불규칙하게 바뀔 수 있습니다.

그래서 입력을 기본 HIGH 상태로 유지하기 위해 저항을 전원에 연결합니다.

```text
VCC
 │
[R]
 │
 ├── 입력
 │
스위치
 │
GND
```

이 저항이 **Pull-Up Resistor**입니다.

## 36. 풀업 저항 회로는 어떻게 동작할까?

스위치가 열려 있으면,

```text
VCC
 │
[R]
 │
입력
```

입력은 HIGH가 됩니다.

스위치를 누르면,

```text
입력
 │
스위치
 │
GND
```

입력이 LOW가 됩니다.

저항이 있기 때문에 VCC와 GND가 직접 단락되지 않습니다.

## 37. 풀다운 저항은 무엇일까?

반대로 기본 상태를 LOW로 만들고 싶다면 저항을 GND 쪽에 연결합니다.

```text
VCC
 │
스위치
 │
 ├── 입력
 │
[R]
 │
GND
```

이를 **Pull-Down Resistor**라고 합니다.

스위치가 열려 있을 때 입력은 LOW입니다.

## 38. 풀업 저항은 왜 0Ω을 쓰지 않을까?

만약 저항 없이 VCC에 직접 연결하면 스위치를 눌렀을 때,

```text
VCC
 │
스위치
 │
GND
```

전원과 GND가 직접 연결됩니다.

매우 큰 전류가 흐를 수 있습니다.

저항을 사용하면,

```text
VCC
 │
10kΩ
 │
스위치
 │
GND
```

전류가 제한됩니다.

## 39. 왜 풀업으로 10kΩ 같은 큰 저항을 사용할까?

입력 핀에는 보통 아주 작은 전류만 필요합니다.

따라서 10kΩ처럼 비교적 큰 저항을 사용할 수 있습니다.

스위치를 눌렀을 때 전류는 5V 기준,

**I = 5 / 10,000**

**= 0.0005A**

즉 **0.5mA**입니다.

불필요한 전력 소비를 줄일 수 있습니다.

## 40. 너무 큰 풀업 저항은 문제가 없을까?

저항이 지나치게 크면 작은 누설 전류나 노이즈에도 입력 전압이 영향을 받을 수 있습니다.

```text
저항 너무 큼
 ↓
입력 약하게 고정
 ↓
노이즈 영향 증가 가능
```

따라서 신호 속도와 회로 환경에 따라 적절한 값을 선택해야 합니다.

## 41. 전류 측정에도 저항을 사용한다

아주 작은 저항을 전류 경로에 넣을 수 있습니다.

```text
배터리 ──[0.001Ω]── 부하
```

전류가 흐르면 작은 전압 강하가 발생합니다.

옴의 법칙,

**V = I × R**

을 이용하면 전류를 계산할 수 있습니다.

## 42. 션트 저항이란?

이런 전류 측정용 저항을 흔히 **Shunt Resistor**라고 합니다.

예를 들어,

- R = 0.001Ω
- I = 50A

라면,

**V = 50 × 0.001**

**= 0.05V**

즉 50mV가 발생합니다.

이 전압을 증폭하거나 ADC로 측정해 전류를 계산할 수 있습니다.

## 43. 션트 저항은 왜 아주 작을까?

전류 측정을 위해 큰 저항을 넣으면 회로에 큰 전압 강하와 발열이 발생합니다.

예를 들어 50A에 0.1Ω이면,

**V = 5V**

이고,

**P = 250W**

입니다.

현실적으로 너무 큰 손실입니다.

그래서 mΩ 단위의 매우 작은 저항을 사용합니다.

## 44. ESC에서도 전류 측정에 저항을 사용할 수 있다

ESC 내부에서는 모터 전류를 측정하기 위해 션트 저항이나 다른 전류 센서를 사용할 수 있습니다.

```text
배터리
 ↓
MOSFET
 ↓
Motor
 ↓
Shunt
 ↓
GND
```

Shunt에서 발생하는 작은 전압을 측정해 MCU가 전류를 계산할 수 있습니다.

이를 이용해,

- Current Limit
- 보호 기능
- 데이터 로깅

등을 구현할 수 있습니다.

## 45. 저항으로 배터리를 방전할 수도 있다

배터리에 저항을 연결하면 전류가 흐르면서 에너지가 열로 변합니다.

예를 들어,

- 8V
- 2Ω 저항

이라면,

**I = 8 / 2 = 4A**

입니다.

저항의 전력은,

**P = 8² / 2**

**= 32W**

입니다.

따라서 최소한 32W 이상의 열을 처리해야 합니다.

실제로는 여유가 더 필요합니다.

## 46. 방전 저항이 매우 뜨거운 이유

배터리 에너지를 거의 전부 열로 바꾸기 때문입니다.

```text
배터리 에너지
     ↓
저항
     ↓
열
```

따라서 고출력 방전 저항에는,

- 큰 세라믹 몸체
- 알루미늄 하우징
- 방열판
- 팬

등이 사용됩니다.

## 47. 알루미늄 하우징 저항은 무엇일까?

고출력 저항 중에는 금속 케이스에 들어 있는 제품이 있습니다.

```text
┌────────────┐
│  1Ω 100W   │
└────────────┘
```

알루미늄 케이스를 방열판에 고정하여 열을 외부로 전달합니다.

표시된 100W를 실제로 사용하려면 지정된 방열 조건이 필요한 경우가 많습니다.

단독으로 공기 중에 두고 100W를 계속 소비할 수 있다는 뜻은 아닐 수 있습니다.

## 48. 저항값 공차란 무엇일까?

100Ω이라고 표시되어 있어도 실제 값이 정확히 100.000Ω인 것은 아닙니다.

예를 들어 공차가 ±5%라면,

```text
100Ω ±5%

→ 95Ω ~ 105Ω
```

범위의 값일 수 있습니다.

대표적인 공차는,

- ±5%
- ±1%
- ±0.5%
- ±0.1%

등입니다.

## 49. 정밀 저항은 언제 필요할까?

LED 전류 제한처럼 값이 조금 달라도 큰 문제가 없는 회로에서는 ±5%도 충분할 수 있습니다.

반대로,

- 계측기
- 전류 측정
- 정밀 분압
- ADC 기준 회로

에서는 ±1% 이하의 정밀 저항을 사용할 수 있습니다.

## 50. 온도에 따라 저항값도 변한다

저항값은 온도에 따라 변할 수 있습니다.

이를 나타내는 것이 **Temperature Coefficient**, 온도계수입니다.

보통 `ppm/°C` 단위를 사용합니다.

예를 들어 100ppm/°C라면 온도가 1°C 변할 때 저항값이 백만분의 100 정도 변할 수 있다는 의미입니다.

정밀 회로에서는 이 특성이 중요합니다.

## 51. 금속도 온도가 올라가면 저항이 증가한다

많은 금속은 온도가 높아질수록 저항이 증가합니다.

```text
온도 ↑
 ↓
원자 진동 증가
 ↓
전자 이동 방해 증가
 ↓
저항 증가
```

그래서 전선이나 모터 권선도 뜨거워지면 저항이 증가합니다.

## 52. RC카 모터에도 저항이 있다

모터 권선은 구리선으로 되어 있습니다.

따라서 아주 작은 저항을 가집니다.

```text
모터 권선

저항
+
인덕턴스
```

모터 전류가 크기 때문에 작은 저항도 큰 열을 만들 수 있습니다.

예를 들어,

- 권선 저항 0.01Ω
- 전류 50A

라면,

**P = 50² × 0.01**

**= 25W**

입니다.

## 53. 배터리에도 내부저항이 있다

배터리 역시 이상적인 전압원이 아닙니다.

내부에 작은 저항이 있는 것처럼 동작합니다.

```text
이상적인 배터리
   +
내부저항
   ↓
실제 배터리
```

전류가 흐르면,

**Vdrop = I × R**

만큼 전압이 떨어집니다.

## 54. 내부저항이 낮은 배터리가 좋은 이유

예를 들어,

### 배터리 A

IR = 0.004Ω

50A에서,

**Vdrop = 0.2V**

### 배터리 B

IR = 0.02Ω

50A에서,

**Vdrop = 1V**

입니다.

내부저항이 큰 배터리는 큰 전류에서 전압이 더 많이 떨어지고 발열도 증가합니다.

## 55. 커넥터와 전선도 저항이다

배터리에서 모터까지의 모든 도체에는 저항이 있습니다.

```text
배터리
 ↓
커넥터
 ↓
전선
 ↓
ESC PCB
 ↓
MOSFET
 ↓
모터선
 ↓
모터 권선
```

각각의 저항은 작지만 큰 전류에서는 무시하기 어려울 수 있습니다.

## 56. 1mΩ도 큰 차이를 만들 수 있다

100A가 흐른다고 생각해봅시다.

저항이 0.001Ω이면,

**Vdrop = 100 × 0.001**

**= 0.1V**

입니다.

전력 손실은,

**P = 100² × 0.001**

**= 10W**

입니다.

즉 고전류 RC에서는 단 **1mΩ**도 상당한 열과 전압강하를 만들 수 있습니다.

## 57. 접촉 불량 커넥터가 뜨거운 이유

커넥터가 느슨하거나 산화되면 접촉저항이 증가합니다.

```text
정상 접점

저항 매우 작음


불량 접점

저항 증가
 ↓
I²R 발열 증가
```

그래서 큰 전류에서 커넥터가 녹거나 변색될 수 있습니다.

## 58. 가변저항은 무엇일까?

저항값을 사람이 바꿀 수 있도록 만든 부품입니다.

이를 **Variable Resistor** 또는 **Potentiometer**라고 합니다.

```text
┌──────── 저항체 ────────┐
             ↑
           접점
```

노브를 돌리면 접점 위치가 바뀌면서 저항값 또는 출력 전압이 변합니다.

## 59. 포텐셔미터는 세 단자를 가진다

일반적인 포텐셔미터는,

```text
A ───── 저항체 ───── B
           ↑
           W
```

세 단자를 가집니다.

중간 접점 W를 이용하면 전압 분배기로 사용할 수 있습니다.

## 60. 서보에도 포텐셔미터가 사용된다

전통적인 RC 서보에서는 출력축 위치를 측정하기 위해 포텐셔미터를 사용합니다.

```text
서보축
  ↓
포텐셔미터
  ↓
출력 전압
  ↓
현재 위치 판단
```

즉 저항의 원리가 RC 서보의 위치 센서에도 사용됩니다.

## 61. NTC와 PTC도 저항의 한 종류다

온도에 따라 저항값이 크게 변하도록 만든 부품을 **Thermistor**라고 합니다.

대표적으로,

### NTC

온도가 올라가면 저항이 감소합니다.

```text
Temperature ↑
Resistance ↓
```

### PTC

온도가 올라가면 저항이 증가합니다.

```text
Temperature ↑
Resistance ↑
```

입니다.

## 62. NTC는 어디에 사용할까?

온도 센서로 많이 사용합니다.

```text
온도 변화
 ↓
NTC 저항 변화
 ↓
분압 전압 변화
 ↓
MCU ADC 측정
 ↓
온도 계산
```

배터리 충전기나 전원 회로에서도 자주 사용됩니다.

## 63. NTC를 돌입전류 제한에 사용하기도 한다

전원 장치의 큰 커패시터는 전원을 처음 켜는 순간 큰 충전 전류를 요구할 수 있습니다.

```text
전원 ON
 ↓
커패시터 비어 있음
 ↓
큰 충전 전류
```

NTC를 직렬로 넣으면 차가운 상태에서는 높은 저항으로 전류를 제한합니다.

전류가 흐르며 뜨거워지면 저항이 낮아집니다.

## 64. PTC는 보호회로에 사용할 수 있다

PTC는 전류가 지나치게 커져 온도가 올라가면 저항이 크게 증가하도록 만들 수 있습니다.

```text
전류 과다
 ↓
PTC 발열
 ↓
저항 증가
 ↓
전류 제한
```

재사용 가능한 퓨즈와 비슷한 역할을 하는 **Polyfuse**도 이런 원리를 이용합니다.

## 65. LDR은 빛에 따라 저항이 변한다

빛에 따라 저항값이 변하는 부품을 **LDR** 또는 Photoresistor라고 합니다.

```text
빛 밝음
 ↓
저항 변화
```

이를 분압 회로에 넣으면 빛의 세기를 전압으로 변환해 측정할 수 있습니다.

## 66. 센서는 왜 저항으로 많이 구현될까?

온도, 빛, 압력 등의 변화가 저항값 변화로 나타나는 센서가 많습니다.

저항값 자체를 MCU가 바로 읽기보다는 분압 회로로 전압으로 바꿉니다.

```text
센서 저항
   ↓
분압
   ↓
전압
   ↓
ADC
   ↓
디지털 값
```

이처럼 저항은 센서와 MCU 사이의 중요한 연결 도구입니다.

## 67. 저항은 신호를 안정시키는 데도 사용한다

디지털 신호선에 작은 직렬 저항을 넣는 경우가 있습니다.

```text
MCU ──[33Ω]──── 신호선
```

빠른 신호의 에지를 약간 완화하여,

- 링잉
- 반사
- EMI

를 줄이는 데 사용할 수 있습니다.

이를 흔히 Series Termination 용도로 사용합니다.

## 68. 저항과 커패시터를 함께 사용하면?

저항과 커패시터를 함께 사용하면 **RC 회로**가 됩니다.

```text
입력 ──[R]──┬── 출력
            │
           [C]
            │
           GND
```

이를 이용해,

- 필터
- 타이머
- 지연 회로
- 노이즈 제거

등을 만들 수 있습니다.

## 69. RC 시정수

저항 R과 커패시터 C를 사용한 회로의 변화 속도는,

**τ = R × C**

로 나타냅니다.

저항이 커지면 커패시터 충·방전이 느려집니다.

```text
R 작음
→ 빠른 충전


R 큼
→ 느린 충전
```

즉 저항은 커패시터의 충·방전 전류도 제어합니다.

## 70. 저항은 인덕터와도 함께 사용된다

인덕터와 저항을 함께 사용하면 RL 회로가 됩니다.

시정수는,

**τ = L / R**

입니다.

저항이 커질수록 인덕터의 저장 에너지가 더 빠르게 소모될 수 있습니다.

## 71. Bleeder Resistor란?

대용량 커패시터에 전원이 꺼진 뒤에도 전압이 남아 있을 수 있습니다.

그래서 커패시터와 병렬로 큰 저항을 연결합니다.

```text
      ┌──[R]──┐
전원 ─┤       ├─
      └──||───┘
          C
```

전원을 끄면 저항을 통해 커패시터가 천천히 방전됩니다.

이 저항을 **Bleeder Resistor**라고 합니다.

## 72. 너무 작은 Bleeder 저항을 사용하면?

평상시에도 전류가 계속 흐릅니다.

예를 들어 12V에 100Ω이라면,

**I = 12 / 100 = 0.12A**

전력은,

**P = 1.44W**

입니다.

계속 에너지를 낭비합니다.

그래서 충분히 큰 저항을 선택합니다.

## 73. 저항의 색띠는 무엇일까?

리드형 저항에는 색띠로 저항값을 표시하는 경우가 많습니다.

대표적인 숫자 대응은 다음과 같습니다.

| 색 | 숫자 |
|---|---:|
| 검정 | 0 |
| 갈색 | 1 |
| 빨강 | 2 |
| 주황 | 3 |
| 노랑 | 4 |
| 초록 | 5 |
| 파랑 | 6 |
| 보라 | 7 |
| 회색 | 8 |
| 흰색 | 9 |

예를 들어,

```text
갈색
검정
빨강
```

이라면,

```text
1
0
×100
```

으로 **1,000Ω = 1kΩ**입니다.

## 74. 네 번째 색은 공차를 나타내기도 한다

일반적인 4밴드 저항에서는 마지막 띠가 공차를 나타냅니다.

예를 들어,

- 금색: ±5%
- 은색: ±10%

등이 사용됩니다.

정밀 저항에서는 5밴드나 6밴드 표기를 사용할 수 있습니다.

## 75. 멀티미터로 저항을 측정할 수 있다

멀티미터의 Ω 모드를 사용하면 저항값을 측정할 수 있습니다.

```text
멀티미터
  │   │
  └─R─┘
```

다만 회로에 연결된 상태에서는 다른 부품과 병렬 경로가 생겨 실제 저항값과 다르게 측정될 수 있습니다.

정확히 측정하려면 회로에서 한쪽 단자를 분리해야 하는 경우가 있습니다.

## 76. 전원이 켜진 상태에서 Ω 측정을 하면 안 된다

저항 측정 모드는 멀티미터가 자체적으로 작은 측정 전류를 흘립니다.

외부에서 전압이 들어오는 상태에서 저항을 측정하면 잘못된 값이 나오거나 계측기가 손상될 수 있습니다.

따라서 일반적으로 전원을 끈 상태에서 측정합니다.

## 77. 저항이 타면 값이 어떻게 될까?

과열된 저항은 여러 형태로 고장날 수 있습니다.

- 저항값 증가
- 단선
- 외형 변색
- 균열

등입니다.

특히 심하게 탄 저항은 색띠를 읽기 어려울 수 있습니다.

## 78. 저항을 교체할 때는 Ω만 같으면 될까?

아닙니다.

최소한,

- 저항값
- 전력 정격
- 공차
- 패키지
- 필요 시 온도계수

를 확인해야 합니다.

예를 들어 10Ω 5W 저항을 10Ω 0.25W 저항으로 교체하면 저항값은 같지만 바로 과열될 수 있습니다.

## 79. 파워저항은 정격보다 여유 있게 사용한다

저항이 최대 정격에서 계속 동작하면 온도가 매우 높아질 수 있습니다.

따라서 실제 설계에서는 여유를 둡니다.

```text
예상 손실 5W

→ 5W 저항을 딱 맞게 쓰기보다
  더 높은 전력 정격 고려
```

특히 주변 온도와 방열 조건을 함께 확인해야 합니다.

## 80. 저항은 단순하지만 회로 전체를 결정한다

저항 하나의 역할은 작아 보이지만 실제 회로에서는 매우 중요합니다.

```text
전원
 │
저항
 │
트랜지스터
 │
MOSFET
 │
센서
```

에서 저항값 하나가 바뀌면,

- 전류
- 전압
- 스위칭 속도
- 센서 기준값
- 발열

이 모두 달라질 수 있습니다.

## 자주 헷갈리는 내용을 정리하면

| 오해 | 바르게 이해하기 |
|---|---|
| 저항은 전류를 소비한다 | 전류 자체가 소비되는 것이 아니라 전기에너지가 주로 열로 변환됨 |
| 저항이 크면 항상 더 뜨겁다 | 전압 고정인지 전류 고정인지에 따라 다름 |
| 저항은 전압을 없앤다 | 회로의 전류와 전압 분배 관계를 만듦 |
| 저항 앞뒤 전류가 다르다 | 직렬 한 경로에서는 같은 전류가 흐름 |
| 두 저항을 병렬로 연결하면 저항이 커진다 | 전체 저항은 더 작아짐 |
| 저항 두 개로 만든 6V는 6V 전원과 같다 | 분압 출력은 부하에 따라 전압이 변함 |
| 0Ω 저항은 아무 의미가 없다 | PCB 점퍼와 회로 옵션 등에 사용 |
| LED에 저항은 없어도 된다 | 일반적인 전압원 구동에서는 전류 제한이 필요 |
| 저항은 전력 정격과 관계없다 | 과도한 전력에서는 과열·손상 가능 |
| 100Ω 저항은 정확히 100Ω이다 | 공차와 온도에 따라 달라질 수 있음 |
| 메탈 기어처럼 저항도 값만 보면 된다 | 전력, 공차, 온도, 구조도 중요 |
| 커넥터는 저항이 0이다 | 작은 접촉저항이 있으며 고전류에서 중요 |
| 굵은 전선은 저항과 관계없다 | 굵을수록 일반적으로 저항이 작아짐 |
| 전류 센서는 반드시 복잡한 IC다 | 작은 션트 저항으로도 전류를 측정할 수 있음 |

## 핵심만 다시 정리하면

저항은 **전류의 흐름을 방해하는 정도를 이용해 회로의 전압과 전류를 원하는 수준으로 만드는 부품**입니다.

가장 중요한 공식은 옴의 법칙입니다.

**V = I × R**

이를 이용하면,

```text
전압을 알면
→ 전류 계산


전류를 알면
→ 필요한 저항 계산


저항을 알면
→ 전압강하 계산
```

이 가능합니다.

또 저항에 전류가 흐르면 전기에너지가 열로 변합니다.

**P = V × I**

**P = I²R**

**P = V²/R**

을 이용해 저항의 발열을 계산할 수 있습니다.

저항을 직렬로 연결하면,

**R전체 = R1 + R2 + ...**

이고,

병렬로 연결하면,

**1/R전체 = 1/R1 + 1/R2 + ...**

입니다.

두 저항을 이용하면,

```text
Vin
 │
R1
 │
 ├── Vout
 │
R2
 │
GND
```

와 같은 분압 회로를 만들 수 있습니다.

그리고 실제 전자회로에서는 저항이 다음과 같이 여러 역할을 수행합니다.

```text
저항

├── 전류 제한
├── LED 보호
├── BJT Base 전류 제어
├── MOSFET Gate 제어
├── Pull-Up / Pull-Down
├── 전압 분배
├── 전류 측정
├── 센서 회로
├── RC 필터
└── 커패시터 방전
```

RC카에서도 저항의 개념은 중요합니다.

배터리 내부저항, 전선 저항, 커넥터 접촉저항, ESC의 MOSFET 저항, 모터 권선 저항이 모두 합쳐져 실제 전압강하와 발열을 만듭니다.

```text
배터리 내부저항
      +
커넥터 저항
      +
전선 저항
      +
ESC 저항
      +
모터 권선 저항
      ↓
전체 손실
```

특히 RC카처럼 수십 A에서 순간적으로 100A 이상이 흐를 수 있는 시스템에서는 몇 mΩ밖에 되지 않는 작은 저항도 무시하기 어렵습니다.

전류가 커질수록,

**P = I²R**

관계 때문에 작은 저항이 큰 발열로 이어질 수 있기 때문입니다.

결국 저항은 단순한 전자부품 하나가 아니라 **전압, 전류, 전력, 발열을 서로 연결하는 전자회로의 가장 기본적인 요소**라고 이해하면 됩니다.
