MOSFET은 전자회로에서 가장 많이 사용되는 트랜지스터 가운데 하나입니다.

컴퓨터의 CPU와 메모리처럼 초소형 디지털 회로부터 전원공급장치, 모터 드라이버, 배터리 보호회로, RC카의 ESC까지 매우 다양한 곳에서 사용됩니다.

MOSFET이 중요한 이유는 **아주 작은 제어 신호로 큰 전류를 빠르게 켜고 끌 수 있기 때문**입니다.

앞에서 살펴본 BJT가 베이스 전류를 이용해 출력 전류를 제어한다면 MOSFET은 기본적으로 **게이트와 소스 사이의 전압**으로 드레인과 소스 사이의 전류 흐름을 제어합니다.

이 글에서는 가장 많이 사용되는 **N채널 Enhancement MOSFET**을 중심으로 동작 원리와 실제 회로에서 중요한 항목을 설명합니다.

## MOSFET을 한눈에 보기

| 항목     | 내용                                                |
| ------ | ------------------------------------------------- |
| 정식 명칭  | Metal-Oxide-Semiconductor Field-Effect Transistor |
| 주요 단자  | Gate, Drain, Source                               |
| 제어 방법  | Gate-Source 사이 전압                                 |
| 주요 역할  | 스위칭, 증폭                                           |
| 물리적 접점 | 없음                                                |
| 주요 특징  | 빠른 스위칭, 작은 구동 전력, 낮은 ON 저항                        |
| 주요 사용처 | 전원회로, 모터 제어, ESC, CPU, 배터리 보호회로                   |

MOSFET을 처음 이해할 때는 **전압으로 켜고 끄는 매우 빠른 전자식 스위치**라고 생각하면 쉽습니다.

## 1. MOSFET에는 세 개의 주요 단자가 있다

MOSFET의 주요 단자는 다음과 같습니다.

* Gate(G): 게이트
* Drain(D): 드레인
* Source(S): 소스

단순화하면 다음과 같은 구조입니다.

```text
        Drain
          │
          │
      [ MOSFET ]
          │
          │
        Source

Gate ─────┤
```

게이트는 MOSFET을 제어하는 단자입니다.

드레인과 소스 사이가 실제 부하 전류가 흐르는 경로입니다.

N채널 MOSFET을 스위치로 사용할 때는 일반적으로 **Gate의 전압을 Source보다 충분히 높게 만들면 MOSFET이 켜집니다.**

## 2. MOSFET은 왜 전압으로 제어할 수 있을까?

MOSFET의 가장 중요한 특징은 Gate가 반도체 채널과 직접 연결되어 있지 않고 **얇은 절연층으로 분리되어 있다는 점**입니다.

단순화하면 다음과 같습니다.

```text
        Gate
         │
     [절연층]
         │
-------------------
   반도체 영역
-------------------
Source           Drain
```

Gate에 전압을 가하면 절연층을 사이에 두고 **전기장**이 만들어집니다.

이 전기장이 반도체 내부의 전하 분포를 변화시킵니다.

그 결과 Source와 Drain 사이에 전류가 흐를 수 있는 **채널(Channel)**이 형성됩니다.

즉 MOSFET 내부에서는 릴레이처럼 금속 접점이 실제로 붙는 것이 아닙니다.

**전기장이 반도체 내부 상태를 변화시켜 전류 통로를 만들어냅니다.**

## 3. Gate 전압이 낮으면 어떻게 될까?

N채널 Enhancement MOSFET에서 Gate와 Source 사이의 전압을 `VGS`라고 합니다.

Gate와 Source의 전압 차이가 충분하지 않으면 Drain과 Source 사이에는 거의 전류가 흐르지 않습니다.

```text
VGS = 0V

Drain
  │
  X
  │
Source
```

이 상태를 스위치에 비유하면 OFF 상태입니다.

반대로 Gate 전압을 충분히 높이면 채널이 형성됩니다.

```text
VGS 충분히 높음

Drain
  │
  │
  │
Source
```

이제 Drain과 Source 사이에 큰 전류가 흐를 수 있습니다.

## 4. 중요한 것은 Gate의 절대 전압이 아니라 VGS다

MOSFET을 이해할 때 가장 많이 실수하는 부분입니다.

Gate가 5V라는 사실만으로 MOSFET이 켜진다고 말할 수 없습니다.

중요한 것은 **Gate와 Source 사이의 전압 차이**입니다.

즉,

**VGS = VG - VS**

입니다.

예를 들어 Source가 0V이고 Gate가 5V라면,

**VGS = 5 - 0 = 5V**

입니다.

하지만 Source가 4V이고 Gate가 5V라면,

**VGS = 5 - 4 = 1V**

밖에 되지 않습니다.

```text
경우 1

Gate  = 5V
Source = 0V

VGS = 5V


경우 2

Gate  = 5V
Source = 4V

VGS = 1V
```

따라서 MOSFET을 제어할 때는 **Gate 전압 자체보다 Source 기준의 Gate 전압을 봐야 합니다.**

## 5. 가장 기본적인 N채널 MOSFET 회로

N채널 MOSFET은 흔히 부하와 GND 사이에 배치합니다.

이를 **Low-Side Switching**이라고 합니다.

```text
        +12V
          │
        [모터]
          │
          │
        Drain
          │
      [ MOSFET ]
          │
        Source
          │
         GND

제어신호 ─── Gate
```

Gate가 낮은 전압이면 MOSFET은 OFF입니다.

```text
Gate = 0V

+12V
  │
[모터]
  │
  X
  │
MOSFET

→ 모터 OFF
```

Gate 전압을 충분히 높이면 MOSFET이 ON됩니다.

```text
Gate = HIGH

+12V
  │
[모터]
  │
  ↓
Drain
  │
MOSFET
  │
Source
  │
GND

→ 모터 ON
```

이렇게 작은 제어회로로 큰 전류를 사용하는 부하를 제어할 수 있습니다.

## 6. VGS(th)는 '완전히 켜지는 전압'이 아니다

MOSFET 데이터시트를 보면 **Gate Threshold Voltage**, 즉 `VGS(th)`라는 항목이 있습니다.

초보자가 가장 많이 오해하는 값 중 하나입니다.

예를 들어 데이터시트에 다음과 같이 적혀 있다고 생각해봅시다.

**VGS(th) = 1V ~ 2.5V**

그러면 흔히

> 게이트에 2.5V만 주면 MOSFET이 완전히 켜지는구나.

라고 생각할 수 있습니다.

하지만 그렇지 않습니다.

`VGS(th)`는 보통 Drain 전류가 **아주 조금 흐르기 시작하는 조건**을 나타냅니다.

즉,

```text
VGS 낮음
   │
   ↓
완전 OFF
   │
   ↓
VGS(th)
   │
   ↓
조금 흐르기 시작
   │
   ↓
더 높은 VGS
   │
   ↓
충분히 ON
```

과 같은 개념입니다.

실제로 큰 전류를 흘리기 위해서는 데이터시트에서 **어떤 VGS에서 RDS(on)이 보장되는지**를 확인해야 합니다.

## 7. Logic-Level MOSFET은 무엇일까?

아두이노나 마이크로컨트롤러는 보통 3.3V 또는 5V 신호를 출력합니다.

그런데 모든 MOSFET이 3.3V나 5V에서 충분히 켜지는 것은 아닙니다.

어떤 MOSFET은 10V 정도의 Gate 전압에서 낮은 RDS(on)이 보장되기도 합니다.

이런 MOSFET을 3.3V 신호로 구동하면 겉으로는 켜진 것처럼 보여도 내부 저항이 높을 수 있습니다.

결과적으로 MOSFET에서 많은 열이 발생할 수 있습니다.

그래서 낮은 Gate 전압에서도 충분히 켜지도록 설계된 MOSFET을 **Logic-Level MOSFET**이라고 부릅니다.

예를 들어 데이터시트에 다음처럼 표시되어 있다면,

```text
RDS(on)

VGS = 10V
VGS = 4.5V
VGS = 2.5V
```

낮은 Gate 전압에서도 ON 저항을 확인할 수 있습니다.

마이크로컨트롤러와 직접 연결할 때는 `VGS(th)`보다 이런 **실제 RDS(on) 보장 조건**을 확인하는 것이 훨씬 중요합니다.

## 8. RDS(on)이 중요한 이유

MOSFET이 충분히 켜져 있어도 Drain과 Source 사이 저항이 완전히 0Ω이 되는 것은 아닙니다.

ON 상태에서 존재하는 저항을 **RDS(on)**이라고 합니다.

예를 들어,

* RDS(on) = 0.01Ω
* 전류 = 10A

라면 전압 강하는

**V = I × R**

**V = 10 × 0.01 = 0.1V**

입니다.

전력 손실은,

**P = I² × R**

이므로,

**P = 10² × 0.01 = 1W**

입니다.

즉 MOSFET에서 1W의 열이 발생합니다.

## 9. 전류가 커질수록 발열은 급격히 증가한다

같은 MOSFET에 20A가 흐른다고 생각해봅시다.

**P = 20² × 0.01**

**P = 4W**

입니다.

전류는 10A에서 20A로 두 배가 되었지만 손실은 1W에서 4W로 **네 배**가 되었습니다.

| 전류  | RDS(on) |    손실 |
| --- | ------: | ----: |
| 5A  |   0.01Ω | 0.25W |
| 10A |   0.01Ω |    1W |
| 20A |   0.01Ω |    4W |
| 30A |   0.01Ω |    9W |

이 때문에 고전류 회로에서는 RDS(on)이 매우 중요합니다.

RC카 ESC가 수십 A 이상의 전류를 다루는 경우 MOSFET의 아주 작은 저항 차이도 발열에 큰 영향을 줍니다.

## 10. 그런데 RDS(on)은 항상 같은 값일까?

그렇지 않습니다.

RDS(on)은 여러 조건에 따라 달라집니다.

대표적으로,

* Gate 전압
* MOSFET 온도
* Drain 전류

등의 영향을 받습니다.

특히 많은 MOSFET은 온도가 상승하면 RDS(on)도 증가합니다.

예를 들어 처음에는 저항이 낮았더라도 MOSFET이 뜨거워지면,

```text
온도 상승
   ↓
RDS(on) 증가
   ↓
전력 손실 증가
   ↓
더 많은 발열
```

과 같은 현상이 나타날 수 있습니다.

따라서 고전류 회로에서는 MOSFET 자체 성능뿐 아니라 방열판, PCB 구리 면적, 냉각팬 등의 설계도 중요합니다.

## 11. Gate에는 정말 전류가 흐르지 않을까?

MOSFET은 흔히 **전압으로 제어하며 Gate 전류가 거의 필요 없다**고 설명합니다.

정상적인 DC 상태에서는 대체로 맞는 설명입니다.

Gate가 절연되어 있기 때문입니다.

하지만 실제 스위칭에서는 이야기가 조금 달라집니다.

Gate는 전기적으로 보면 **작은 커패시터와 비슷한 특성**을 가지고 있습니다.

```text
Gate
 │
 ├──||── Source
 │
 └──||── Drain
```

따라서 MOSFET을 켜려면 Gate에 전하를 넣어야 하고, 끄려면 그 전하를 빼야 합니다.

즉,

```text
MOSFET ON

Gate 충전
   ↓
VGS 상승
   ↓
MOSFET ON


MOSFET OFF

Gate 방전
   ↓
VGS 하강
   ↓
MOSFET OFF
```

이 과정에서는 순간적으로 Gate 전류가 흐릅니다.

따라서 **MOSFET Gate에는 전류가 전혀 필요 없다**는 표현은 정확하지 않습니다.

## 12. Gate Charge란 무엇일까?

MOSFET 데이터시트에는 흔히 **Total Gate Charge**, 즉 `Qg`라는 항목이 있습니다.

Gate를 원하는 전압까지 충전하기 위해 필요한 전하량을 나타냅니다.

예를 들어 Gate Charge가 큰 MOSFET은 켜고 끌 때 더 많은 전하를 이동시켜야 합니다.

따라서 같은 드라이버를 사용한다면 Gate Charge가 큰 MOSFET은 스위칭 시간이 길어질 수 있습니다.

```text
Gate Charge 작음

충전 ███
→ 빠르게 ON


Gate Charge 큼

충전 ███████████
→ 상대적으로 느리게 ON
```

이 값은 특히 수십 kHz 이상의 빠른 PWM이나 전원 변환 회로에서 중요합니다.

## 13. MOSFET은 왜 천천히 켜면 뜨거워질까?

MOSFET이 완전히 OFF일 때는 전류가 거의 흐르지 않습니다.

```text
OFF

전압 큼
전류 ≈ 0

P ≈ 0
```

완전히 ON되면 전류는 크지만 MOSFET 양단 전압은 작습니다.

```text
ON

전압 작음
전류 큼

P 비교적 작음
```

문제는 OFF와 ON 사이의 **중간 상태**입니다.

```text
전환 중

전압도 큼
전류도 큼
```

전력은

**P = V × I**

이므로 전압과 전류가 동시에 큰 순간에는 큰 전력 손실이 발생합니다.

이것을 **Switching Loss**, 스위칭 손실이라고 합니다.

따라서 MOSFET을 빠르게 켜고 끄면 이 중간 구간을 짧게 통과할 수 있습니다.

## 14. 전도 손실과 스위칭 손실은 다르다

MOSFET에서 발생하는 대표적인 손실은 크게 두 가지로 생각할 수 있습니다.

### 전도 손실

MOSFET이 ON 상태일 때 RDS(on) 때문에 발생합니다.

**Pconduct ≈ I² × RDS(on)**

### 스위칭 손실

MOSFET이 OFF와 ON 사이를 이동할 때 발생합니다.

단순화하면,

**Pswitch ≈ 1/2 × V × I × (tr + tf) × f**

처럼 생각할 수 있습니다.

* V: 스위칭 전압
* I: 스위칭 전류
* tr: 상승 시간
* tf: 하강 시간
* f: 스위칭 주파수

실제 계산은 회로 조건에 따라 더 복잡하지만 중요한 점은 **스위칭이 느리거나 스위칭 횟수가 많아질수록 손실이 증가한다는 것**입니다.

## 15. PWM과 MOSFET은 왜 궁합이 좋을까?

PWM은 MOSFET을 매우 빠르게 ON/OFF하면서 평균적인 출력을 조절하는 방식입니다.

예를 들어 50% Duty Cycle이라면,

```text
ON      OFF

████____████____████____
```

한 주기의 절반만 MOSFET이 켜져 있습니다.

25%라면,

```text
██______██______██______
```

75%라면,

```text
██████__██████__██████__
```

처럼 됩니다.

MOSFET은 기계적 접점이 없기 때문에 이런 빠른 ON/OFF를 매우 많이 반복할 수 있습니다.

이 때문에 모터 제어, 전원공급장치, LED 밝기 조절 등에 널리 사용됩니다.

## 16. PWM으로 모터 속도를 조절하는 원리

12V 모터를 예로 들어보겠습니다.

MOSFET이 계속 ON이면 모터에 거의 12V가 공급됩니다.

```text
Duty 100%

████████████████████

→ 최대 출력에 가까움
```

50% Duty Cycle에서는 12V가 절반의 시간 동안 공급됩니다.

```text
Duty 50%

████____████____████
```

모터의 코일과 기계적 관성 때문에 모터가 매번 완전히 멈췄다가 다시 도는 것이 아니라 평균적인 효과를 받아 중간 속도로 회전합니다.

이 때문에 MOSFET을 선형 영역에서 일부만 켜서 속도를 줄이는 것보다 PWM을 이용하는 방법이 훨씬 효율적입니다.

## 17. MOSFET을 반쯤 켜서 모터 속도를 조절하면 안 될까?

가능은 하지만 큰 전류를 다루는 경우 매우 비효율적일 수 있습니다.

예를 들어 MOSFET에서 5V가 떨어지고 10A가 흐른다고 생각해봅시다.

**P = V × I**

**P = 5 × 10 = 50W**

MOSFET 하나에서 50W가 열로 변합니다.

반면 PWM에서는 MOSFET을 가능한 한

* 완전히 ON
* 완전히 OFF

상태로 동작시키기 때문에 손실을 크게 줄일 수 있습니다.

그래서 고출력 모터 제어에서는 PWM이 매우 중요합니다.

## 18. Gate Resistor는 왜 사용할까?

MOSFET Gate 앞에 작은 저항을 넣는 회로를 자주 볼 수 있습니다.

```text
제어신호 ──[ Gate 저항 ]── Gate
```

Gate가 커패시터처럼 동작하기 때문에 Gate를 충전할 때 순간적으로 큰 전류가 흐를 수 있습니다.

Gate 저항은 이 전류를 제한하고 스위칭 속도를 조절하는 데 사용됩니다.

하지만 저항이 지나치게 크면 Gate 충전과 방전이 느려집니다.

```text
Gate 저항 너무 큼

Gate 천천히 충전
      ↓
MOSFET 천천히 ON
      ↓
스위칭 손실 증가
```

반대로 너무 작으면 빠르게 스위칭할 수 있지만 링잉, EMI, 드라이버의 순간 전류 부담 등이 커질 수 있습니다.

그래서 실제 설계에서는 속도와 안정성 사이의 균형을 잡습니다.

## 19. Gate Pull-Down 저항은 왜 필요할까?

MOSFET Gate가 아무것에도 연결되지 않은 상태를 **Floating** 상태라고 합니다.

Gate는 커패시터처럼 전하를 저장할 수 있기 때문에 이전에 남아 있던 전하나 주변 노이즈 때문에 MOSFET이 예상치 않게 켜질 수 있습니다.

그래서 N채널 MOSFET에서는 흔히 Gate와 Source 사이에 저항을 연결합니다.

```text
           Gate
제어 ───────┤
           │
         [10kΩ]
           │
         Source
           │
          GND
```

이를 **Gate Pull-Down Resistor**라고 합니다.

제어 신호가 연결되지 않았을 때 Gate의 전하를 빼서 MOSFET을 확실하게 OFF 상태로 만들어줍니다.

## 20. Gate Driver가 필요한 이유

작은 MOSFET 하나를 낮은 주파수로 제어하는 회로에서는 마이크로컨트롤러가 Gate를 직접 구동할 수도 있습니다.

하지만 고출력 회로에서는 별도의 **Gate Driver**를 사용하는 경우가 많습니다.

Gate Driver의 역할은 단순합니다.

**MOSFET Gate를 매우 빠르게 충전하고 방전하는 것**입니다.

```text
마이크로컨트롤러
       │
       ↓
 [ Gate Driver ]
       │
       ↓
    MOSFET
       │
       ↓
      부하
```

Gate Driver는 짧은 순간에 큰 Gate 전류를 공급하거나 빼낼 수 있습니다.

이렇게 하면 MOSFET이 ON/OFF 중간 영역에 머무르는 시간을 줄일 수 있어 스위칭 손실이 감소합니다.

## 21. High-Side MOSFET은 왜 제어가 더 어려울까?

지금까지 살펴본 회로는 MOSFET이 부하 아래쪽에 있는 Low-Side 방식입니다.

```text
+V
 │
부하
 │
MOSFET
 │
GND
```

이 경우 Source가 거의 GND에 있으므로 Gate에 5V 또는 10V를 공급하기 쉽습니다.

하지만 High-Side에서는 MOSFET이 부하 위쪽에 있습니다.

```text
+V
 │
MOSFET
 │
부하
 │
GND
```

N채널 MOSFET을 High-Side에서 사용하려면 Source 전압보다 Gate를 더 높게 만들어야 합니다.

예를 들어 Source가 12V까지 올라가는데 MOSFET을 `VGS = 10V`로 구동하려면 Gate가 약 22V까지 올라가야 합니다.

```text
Source = 12V

필요 VGS = 10V

Gate ≈ 22V
```

그래서 High-Side N채널 MOSFET 구동에는 **Bootstrap 회로나 High-Side Gate Driver** 등이 사용됩니다.

## 22. MOSFET의 Body Diode는 무엇일까?

파워 MOSFET에는 구조상 **Body Diode**라는 다이오드가 존재합니다.

단순화하면 MOSFET과 다이오드가 같이 있는 것처럼 볼 수 있습니다.

```text
Drain
  │
 [MOSFET]
  │
Source

내부에 Body Diode 존재
```

이 다이오드는 모터 제어와 H-Bridge, 인버터 회로에서 중요한 역할을 합니다.

하지만 Body Diode의 성능이 항상 충분한 것은 아니므로 고속·고효율 회로에서는 다이오드의 역회복 특성 등도 중요하게 고려합니다.

## 23. MOSFET의 최대 전류만 보고 고르면 안 된다

MOSFET 데이터시트에는 종종 매우 큰 Drain Current가 표시되어 있습니다.

예를 들어,

**ID = 100A**

라고 쓰여 있다고 해서 실제 회로에서 무조건 100A를 안정적으로 흘릴 수 있다는 뜻은 아닙니다.

최대 전류는 특정 온도와 방열 조건을 전제로 합니다.

실제 사용 가능 전류는 다음 요소에 영향을 받습니다.

* RDS(on)
* 패키지
* PCB 패턴
* 방열판
* 주변 온도
* Gate 전압
* 스위칭 주파수
* 냉각 방식

따라서 MOSFET을 선택할 때 **최대 전류 숫자 하나만 보는 것은 위험합니다.**

## 24. 최대 Drain-Source 전압도 중요하다

MOSFET에는 견딜 수 있는 최대 Drain-Source 전압이 있습니다.

이를 보통 **VDS Max** 또는 Breakdown Voltage로 표시합니다.

예를 들어 12V 회로라고 해서 정확히 12V만 견디는 MOSFET을 사용할 수는 없습니다.

모터와 같은 유도성 부하는 스위칭할 때 순간적인 전압 스파이크를 발생시킬 수 있기 때문입니다.

그래서 실제 설계에서는 예상되는 최대 전압보다 충분히 높은 VDS 정격을 가진 MOSFET을 선택합니다.

## 25. RC카 ESC에서는 MOSFET이 어떻게 사용될까?

RC카 브러시리스 ESC에서는 여러 MOSFET을 이용하여 배터리의 직류를 모터를 회전시키는 3상 전류로 변환합니다.

브러시리스 모터에는 보통 세 개의 선이 있습니다.

```text
ESC
 │
 ├── U
 ├── V
 └── W
      │
   BLDC Motor
```

각 상에는 위쪽과 아래쪽 MOSFET이 있습니다.

```text
      Battery +

        MOSFET
           │
U ─────────┤
           │
        MOSFET
           │
          GND
```

이 회로를 **Half Bridge**라고 합니다.

브러시리스 모터에는 세 상이 있으므로 기본적으로 Half Bridge 세 개를 사용합니다.

```text
             Battery +

         ┌─────┬─────┐
       MOS    MOS    MOS
         │      │      │
         U      V      W
         │      │      │
       MOS    MOS    MOS
         └─────┴─────┘
              │
             GND
```

즉 기본적인 3상 인버터는 **6개의 스위칭 위치**를 갖습니다.

실제 ESC는 전류 용량을 늘리고 발열을 줄이기 위해 각 위치에 MOSFET을 여러 개 병렬로 사용하는 경우도 있습니다.

## 26. ESC에서 MOSFET이 뜨거워지는 이유

ESC의 MOSFET 발열은 한 가지 이유로 발생하는 것이 아닙니다.

대표적으로,

* RDS(on)에 의한 전도 손실
* ON/OFF 과정의 스위칭 손실
* Body Diode 관련 손실
* 배선과 PCB 저항
* Gate 구동 손실

등이 있습니다.

```text
ESC 발열

전도 손실
   +
스위칭 손실
   +
기타 손실
   ↓
열 발생
```

그래서 ESC 제조사는 낮은 RDS(on)의 MOSFET, 적절한 Gate Driver, 넓은 PCB 구리 면적, 알루미늄 방열판, 냉각팬 등을 사용합니다.

## 27. ESC의 PWM 주파수를 높이면 무조건 좋은가?

PWM 주파수가 높아지면 모터 제어가 더 부드러워질 수 있고 가청 소음을 줄이는 데 유리할 수 있습니다.

하지만 MOSFET 입장에서는 더 자주 ON/OFF해야 합니다.

예를 들어,

```text
8kHz

1초에 8,000번 스위칭


32kHz

1초에 32,000번 스위칭
```

스위칭 한 번마다 작은 손실이 발생하므로 주파수가 높아지면 스위칭 손실도 증가할 수 있습니다.

따라서 PWM 주파수는 무조건 높을수록 좋은 것이 아니라,

* 모터 특성
* MOSFET 특성
* Gate Driver
* 발열
* 제어감

등을 고려해야 합니다.

RC카 ESC에서 PWM 주파수 설정이 주행감뿐 아니라 ESC와 모터의 온도에도 영향을 줄 수 있는 이유입니다.

## 28. MOSFET을 병렬로 연결하는 이유

큰 전류를 처리하기 위해 MOSFET 여러 개를 병렬로 사용하는 경우가 있습니다.

```text
        ┌─ MOSFET ─┐
입력 ───┼─ MOSFET ─┼── 출력
        └─ MOSFET ─┘
```

이상적으로 전류가 균등하게 나뉜다면 각 MOSFET이 부담하는 전류가 줄어듭니다.

예를 들어 60A를 MOSFET 세 개가 균등하게 담당하면 각각 약 20A를 처리합니다.

하지만 실제 회로에서는 PCB 배선 저항, Gate 구동, 온도 등의 차이 때문에 완벽하게 똑같이 나뉘지는 않습니다.

그래서 병렬 MOSFET 설계에서는 PCB 레이아웃도 매우 중요합니다.

## 29. BJT와 MOSFET을 다시 비교하면

| 특징        | BJT      | MOSFET         |
| --------- | -------- | -------------- |
| 제어 방식     | Base 전류  | Gate 전압        |
| 입력 전류     | 지속적으로 필요 | 정상 상태에서 매우 작음  |
| 입력 특성     | PN 접합    | 커패시터와 유사       |
| ON 손실     | VCE(sat) | RDS(on)        |
| 빠른 스위칭    | 가능       | 매우 적합          |
| PWM       | 가능       | 매우 많이 사용       |
| 고전류 모터 제어 | 가능       | 매우 일반적         |
| 주요 활용     | 증폭, 스위칭  | 전원, 모터, 디지털 회로 |

MOSFET이 BJT를 완전히 대체한 것은 아닙니다.

회로의 목적과 전압, 전류, 주파수, 비용 등에 따라 BJT가 더 적합한 경우도 있습니다.

하지만 **고효율 스위칭과 전력 제어**에서는 MOSFET이 매우 중요한 위치를 차지합니다.

## 자주 헷갈리는 내용을 정리하면

| 오해                                   | 바르게 이해하기                        |
| ------------------------------------ | ------------------------------- |
| Gate에 5V를 주면 무조건 켜진다                 | Source 기준 VGS를 확인해야 함           |
| VGS(th)가 2V면 2V에서 완전히 ON이다           | 전류가 조금 흐르기 시작하는 기준에 가까움         |
| MOSFET ON 저항은 0Ω이다                   | 실제로는 RDS(on)이 존재함               |
| 최대 전류 100A면 항상 100A를 흘릴 수 있다         | 온도와 방열 조건에 크게 좌우됨               |
| Gate에는 전류가 전혀 흐르지 않는다                | 스위칭할 때 Gate 충·방전 전류가 흐름         |
| Gate Charge가 커도 상관없다                 | 빠른 스위칭에서 Gate Driver 부담과 손실에 영향 |
| MOSFET은 천천히 켜도 된다                    | 중간 영역에 오래 머물면 큰 발열이 발생할 수 있음    |
| PWM 주파수는 높을수록 무조건 좋다                 | 스위칭 손실도 함께 증가할 수 있음             |
| MOSFET 여러 개를 병렬로 달면 전류가 완벽히 균등하게 나뉜다 | PCB와 온도 조건에 따라 차이가 생길 수 있음      |
| 12V 회로에는 12V MOSFET이면 된다             | 스파이크를 고려해 충분한 VDS 여유가 필요함       |

## 핵심만 다시 정리하면

MOSFET은 **Gate와 Source 사이의 전압으로 Drain과 Source 사이의 전류를 제어하는 트랜지스터**입니다.

가장 중요한 관계는 다음과 같습니다.

```text
Gate 전압 변화
      ↓
VGS 변화
      ↓
반도체 내부 전기장 변화
      ↓
Channel 형성
      ↓
Drain-Source 전류 변화
```

MOSFET을 실제 스위칭 회로에서 사용할 때는 단순히 최대 전압과 최대 전류만 보는 것이 아니라,

* VGS
* VGS(th)
* RDS(on)
* Gate Charge
* 스위칭 속도
* VDS 정격
* 발열
* 방열

등을 함께 확인해야 합니다.

특히 고전류 회로에서는,

**전도 손실 = I² × RDS(on)**

이라는 관계 때문에 RDS(on)의 작은 차이도 큰 발열 차이를 만들 수 있습니다.

또 빠른 PWM 회로에서는 MOSFET이 ON과 OFF 사이를 얼마나 빠르게 이동하는지가 중요합니다.

그래서 실제 고성능 회로는 단순히 좋은 MOSFET 하나를 사용하는 것만으로 완성되지 않습니다.

```text
MOSFET
  +
Gate Driver
  +
PCB 설계
  +
방열
  +
제어 알고리즘
  ↓
고효율 스위칭 회로
```

RC카 ESC 역시 같은 원리입니다.

배터리의 큰 전류를 여러 MOSFET이 빠르게 스위칭하고, Gate Driver와 제어 MCU가 그 타이밍을 결정하며, 방열판과 팬이 발생하는 열을 처리합니다.

따라서 MOSFET의 원리를 이해하면 ESC에서 왜 MOSFET이 뜨거워지는지, PWM 주파수가 왜 온도에 영향을 주는지, 고급 ESC가 왜 더 효율적인지까지 하나의 원리로 연결해서 이해할 수 있습니다.
