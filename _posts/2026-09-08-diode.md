다이오드(Diode)는 전자회로에서 가장 기본적인 반도체 부품 가운데 하나입니다.

가장 단순하게 설명하면 **전류가 한쪽 방향으로는 흐르기 쉽고, 반대 방향으로는 거의 흐르지 않도록 하는 부품**입니다.

하지만 실제로는 단순한 일방통행 스위치가 아닙니다.

다이오드는 P형 반도체와 N형 반도체를 붙여 만든 **PN 접합**의 전기적 특성을 이용합니다. 이 PN 접합이 어떻게 동작하는지 이해하면 다이오드뿐 아니라 BJT 트랜지스터, LED, 태양전지 등 여러 반도체 소자의 원리도 자연스럽게 연결됩니다.

이 글에서는 일반적인 실리콘 PN 접합 다이오드를 중심으로 설명하고, 이후 쇼트키 다이오드, 제너 다이오드, LED와 실제 회로에서 자주 사용하는 플라이백 다이오드까지 살펴봅니다.

## 먼저 다이오드를 한눈에 보기

| 항목            | 내용                    |
| ------------- | --------------------- |
| 기본 구조         | P형 반도체 + N형 반도체       |
| 주요 단자         | Anode(A), Cathode(K)  |
| 주요 기능         | 한쪽 방향 전류 통과, 반대 방향 차단 |
| 대표적인 활용       | 정류, 보호, 전압 제한, 신호 처리  |
| 일반 실리콘 순방향 전압 | 약 0.6~0.7V 부근         |
| 대표 종류         | 정류 다이오드, 쇼트키, 제너, LED |
| 기계적 움직임       | 없음                    |

다이오드는 릴레이처럼 물리적인 접점이 움직이지 않습니다.

반도체 내부의 전하 분포가 전압에 따라 바뀌면서 전류가 흐르거나 차단됩니다.

## 1. 다이오드에는 두 개의 단자가 있다

다이오드의 두 단자는 다음과 같습니다.

* Anode(A): 애노드
* Cathode(K): 캐소드

회로 기호는 다음과 같습니다.

```text
Anode                  Cathode
  A                       K
  │                       │
──┤>|─────────────────────
```

실제 다이오드 부품에는 보통 한쪽에 띠가 표시되어 있습니다.

그 띠가 있는 쪽이 일반적으로 **Cathode**입니다.

```text
실제 다이오드

────[       | ]────
           ↑
        Cathode
        표시 띠
```

회로에 사용할 때 방향이 중요하기 때문에 이 표시를 확인해야 합니다.

## 2. P형과 N형 반도체는 무엇일까?

다이오드는 P형 반도체와 N형 반도체를 붙여 만듭니다.

먼저 반도체란 전기가 아주 잘 흐르는 금속과 거의 흐르지 않는 절연체의 중간적인 성질을 가진 물질입니다.

대표적으로 실리콘이 많이 사용됩니다.

순수한 실리콘에 아주 적은 양의 불순물을 넣으면 전기적인 특성을 바꿀 수 있습니다.

### N형 반도체

N형 반도체에는 전도에 참여할 수 있는 **전자**가 상대적으로 많습니다.

```text
N형 반도체

전자
● ● ● ● ●
```

여기서 N은 Negative를 의미한다고 이해하면 쉽습니다.

### P형 반도체

P형 반도체에서는 전자가 비어 있는 상태를 **정공(Hole)**이라는 개념으로 다룹니다.

```text
P형 반도체

정공
○ ○ ○ ○ ○
```

정공은 실제 입자가 따로 존재한다기보다 **전자가 비어 있는 자리**를 전하 운반자로 표현한 개념입니다.

회로 해석에서는 정공이 양전하처럼 이동한다고 생각할 수 있습니다.

## 3. P형과 N형을 붙이면 무슨 일이 일어날까?

P형과 N형 반도체를 붙이면 경계에서 바로 변화가 일어납니다.

```text
P형                 N형

○ ○ ○ ○ | ● ● ● ●
        접합면
```

N형 쪽에는 전자가 많고 P형 쪽에는 정공이 많기 때문에 접합 직후에는 서로 가까운 쪽의 전자와 정공이 결합합니다.

```text
P형                 N형

○ ○ ○    |    ● ● ●
       ← 결합 →
```

그 결과 접합 부근에서는 자유롭게 이동할 수 있는 전자와 정공이 줄어듭니다.

이 영역을 **공핍층(Depletion Region)**이라고 합니다.

```text
P형        공핍층       N형

○ ○ ○   |       |   ● ● ●
```

공핍층 내부에는 이동하기 어려운 이온화된 원자들이 남아 전기장을 만듭니다.

이 전기장은 추가적인 전하 운반자가 쉽게 접합을 넘어가는 것을 방해합니다.

즉 PN 접합은 처음부터 무조건 전류가 흐르는 구조가 아닙니다.

## 4. 다이오드에 아무 전압도 걸지 않으면?

외부에서 전압을 걸지 않은 상태에서는 PN 접합 주변에 공핍층이 형성되어 있습니다.

```text
P형        공핍층        N형

○ ○ ○   |██████|   ● ● ●
```

이 공핍층은 일종의 장벽처럼 작용합니다.

전자와 정공이 자유롭게 반대쪽으로 이동하지 못하게 막습니다.

따라서 외부 전압이 없는 상태에서는 다이오드를 통해 큰 전류가 지속적으로 흐르지 않습니다.

## 5. 순방향 전압을 걸면 어떻게 될까?

P형 쪽에 높은 전압을, N형 쪽에 낮은 전압을 연결하는 것을 **순방향 바이어스(Forward Bias)**라고 합니다.

```text
+                            -

P형         PN 접합         N형
 │                            │
 └──────── 전원 ──────────────┘
```

즉,

* Anode를 +
* Cathode를 -

쪽에 연결합니다.

외부 전압이 PN 접합 내부의 장벽을 약하게 만드는 방향으로 작용합니다.

그 결과 공핍층이 좁아집니다.

```text
순방향

P형       공핍층      N형

○ ○ ○ ○ |██| ● ● ● ●
```

전압이 충분히 올라가면 많은 전하 운반자가 접합을 넘어갈 수 있게 되고 전류가 크게 증가합니다.

따라서 다이오드는 순방향에서 전류가 흐르기 쉬워집니다.

## 6. 다이오드는 정확히 0.7V에서 갑자기 켜질까?

흔히 실리콘 다이오드를 설명할 때

> 0.7V 이상에서 켜진다.

라고 말합니다.

초보 단계에서는 유용한 근사이지만 실제 동작은 조금 다릅니다.

다이오드의 전류는 특정 전압에서 갑자기 0에서 큰 값으로 바뀌는 것이 아니라 **순방향 전압이 올라갈수록 매우 빠르게 증가하는 곡선**을 가집니다.

```text
전류
 ↑
 │                     /
 │                   /
 │                /
 │             /
 │         ___/
 │________/
 └────────────────────→ 전압
           약 0.6~0.7V 부근
```

따라서 0.7V는 절대적인 ON/OFF 경계가 아닙니다.

전류와 온도, 다이오드 종류에 따라 순방향 전압은 달라집니다.

예를 들어 작은 전류에서는 0.6V보다 낮을 수 있고 큰 전류에서는 0.7V보다 높을 수 있습니다.

## 7. 순방향 전압 강하는 무엇일까?

다이오드에 순방향으로 전류가 흐를 때 다이오드 양단에는 일정한 전압 차이가 생깁니다.

이를 **Forward Voltage**, 보통 `VF`라고 합니다.

예를 들어 실리콘 다이오드의 순방향 전압을 약 0.7V라고 가정해봅시다.

```text
5V ──>|── 저항 ── GND
     다이오드
```

다이오드에서 약 0.7V가 떨어진다면 저항에는 약

**5V - 0.7V = 4.3V**

가 걸립니다.

저항이 1kΩ이라면 전류는

**I = V / R**

**I = 4.3 / 1,000 = 0.0043A**

즉 약 **4.3mA**입니다.

이처럼 다이오드가 포함된 회로에서는 순방향 전압 강하를 고려해야 합니다.

## 8. 반대 방향으로 연결하면 어떻게 될까?

이번에는 P형 쪽을 -, N형 쪽을 +에 연결해봅시다.

이를 **역방향 바이어스(Reverse Bias)**라고 합니다.

```text
-                            +

P형         PN 접합         N형
 │                            │
 └──────── 전원 ──────────────┘
```

외부 전압이 접합 내부의 장벽을 더욱 크게 만드는 방향으로 작용합니다.

따라서 공핍층이 넓어집니다.

```text
역방향

P형          공핍층          N형

○ ○ |██████████████| ● ●
```

이 상태에서는 전류가 거의 흐르지 않습니다.

그래서 다이오드를 흔히 **전류를 한쪽 방향으로만 흐르게 하는 부품**이라고 설명합니다.

## 9. 역방향에서는 전류가 완전히 0일까?

실제 다이오드에서는 역방향 전류가 완전히 0은 아닙니다.

매우 작은 **Leakage Current**, 즉 누설 전류가 흐를 수 있습니다.

일반적인 회로에서는 무시할 수 있을 만큼 작을 수 있지만 온도가 높아지거나 특정 종류의 다이오드에서는 중요한 요소가 될 수 있습니다.

따라서

> 역방향에서는 절대 전류가 흐르지 않는다.

보다는

> 정상적인 역방향 동작에서는 매우 작은 누설 전류만 흐른다.

라고 이해하는 것이 더 정확합니다.

## 10. 역방향 전압을 계속 높이면 어떻게 될까?

다이오드는 역방향 전압을 무한히 견딜 수 없습니다.

역방향 전압이 특정 값 이상으로 올라가면 **Breakdown**, 즉 항복 현상이 발생합니다.

```text
역방향 전압 증가

낮음
 ↓
거의 차단
 ↓
더 증가
 ↓
Breakdown
 ↓
큰 역방향 전류
```

일반 다이오드는 이 상태에서 전류를 제한하지 않으면 손상될 수 있습니다.

따라서 데이터시트에서 허용 가능한 최대 역방향 전압을 확인해야 합니다.

## 11. 다이오드의 가장 대표적인 용도는 정류다

교류는 전압의 방향이 계속 바뀝니다.

```text
AC

 +      +      +
 │     / \    / \
0┼────/───\──/───\────
 │   /     \/     \
 -  -
```

그런데 많은 전자회로는 일정한 방향의 직류가 필요합니다.

다이오드는 한쪽 방향만 통과시키기 때문에 교류를 직류 방향으로 바꾸는 **정류(Rectification)**에 사용할 수 있습니다.

## 12. 다이오드 하나로 반파 정류하기

교류 전원과 부하 사이에 다이오드 하나를 넣어봅시다.

```text
AC ──>|── 부하 ── AC
```

전압이 다이오드 순방향인 반주기에는 전류가 흐릅니다.

```text
입력

 +      +      +
 │     / \    / \
0┼────/───\──/───\────
 │   /     \/     \
 -


출력

 +      +      +
 │     / \    / \
0┼────/───\──/───\────
 │
 │
```

반대 방향의 반주기에는 다이오드가 전류를 차단합니다.

이를 **반파 정류(Half-Wave Rectification)**라고 합니다.

## 13. 브리지 정류는 무엇일까?

교류의 양쪽 반주기를 모두 사용하려면 다이오드 네 개를 이용한 **브리지 정류 회로**를 사용할 수 있습니다.

```text
          ┌──>|──┐
AC ───────┤      ├──── +
          │      │
          │ 부하 │
          │      │
AC ───────┤      ├──── -
          └──|<──┘

실제로는 다이오드 4개 사용
```

입력 교류의 방향이 바뀌어도 부하를 통과하는 전류의 방향은 동일하게 만들어집니다.

따라서 출력은 다음과 비슷합니다.

```text
입력 AC

    / \      / \
___/   \____/   \____
   \   /    \   /
    \_/      \_/


정류 후

    / \      / \
___/   \____/   \____
    / \      / \
___/   \____/   \____
```

아직 완전히 일정한 DC는 아니지만 전류의 방향은 한쪽으로 정리됩니다.

여기에 커패시터 등을 추가하면 전압의 출렁임을 줄일 수 있습니다.

## 14. 전원 극성 보호에도 사용할 수 있다

전자제품에 배터리를 반대로 연결하면 회로가 손상될 수 있습니다.

다이오드를 직렬로 넣으면 잘못된 방향의 전류를 차단할 수 있습니다.

```text
배터리 + ──>|── 회로
```

정상 방향에서는 전류가 흐릅니다.

배터리를 반대로 연결하면 다이오드가 역방향이 되어 전류를 차단합니다.

다만 일반 실리콘 다이오드는 순방향 전압 강하 때문에 전력 손실이 생깁니다.

예를 들어,

* 전류 2A
* 다이오드 순방향 전압 0.7V

라면 다이오드 손실은

**P = V × I**

**P = 0.7 × 2 = 1.4W**

입니다.

따라서 큰 전류에서는 다른 보호 방식이나 MOSFET을 이용한 역극성 보호 회로를 사용하기도 합니다.

## 15. 모터나 릴레이 코일에 다이오드를 붙이는 이유

모터, 릴레이, 솔레노이드처럼 코일이 있는 부하는 전류가 흐를 때 자기장에 에너지를 저장합니다.

```text
전원
 │
[코일]
 │
트랜지스터
 │
GND
```

트랜지스터가 켜져 있을 때 코일에 전류가 흐릅니다.

그런데 트랜지스터를 갑자기 끄면 코일은 흐르던 전류를 계속 유지하려고 합니다.

이 때문에 순간적으로 큰 전압이 발생할 수 있습니다.

```text
ON

전원 → 코일 → 트랜지스터 → GND


갑자기 OFF

코일 전류가 갈 곳 없음
        ↓
큰 전압 발생
```

이 전압은 트랜지스터나 MOSFET을 손상시킬 수 있습니다.

## 16. 플라이백 다이오드는 전류가 돌아갈 길을 만든다

코일 양단에 다이오드를 다음과 같이 연결합니다.

```text
       +V
        │
        ├───────┐
        │       │
      [코일]   [다이오드]
        │       │
        ├───────┘
        │
    MOSFET
        │
       GND
```

정상적으로 MOSFET이 켜져 있을 때는 다이오드가 역방향이므로 거의 전류가 흐르지 않습니다.

MOSFET이 꺼지는 순간에는 코일 전압의 방향이 바뀌고 다이오드가 순방향으로 동작합니다.

```text
MOSFET OFF

      ┌──── 다이오드 ────┐
      │                   │
      └────── 코일 ───────┘

전류가 이 경로를 통해 순환
```

이렇게 코일 전류가 안전하게 감소할 수 있는 경로를 만들어줍니다.

이를 **Flyback Diode**, **Freewheel Diode**라고 합니다.

## 17. 왜 다이오드 방향을 반대로 연결할까?

플라이백 다이오드를 보면 평소 전원 방향과 반대로 연결되어 있습니다.

```text
       +12V
         │
         ├─────|<─────┐
         │   다이오드 │
       [코일]          │
         │             │
         └─────────────┘
         │
      MOSFET
         │
        GND
```

평상시에 다이오드가 순방향이면 전원이 다이오드를 통해 바로 흐르면서 사실상 단락에 가까운 상태가 될 수 있습니다.

따라서 평소에는 **역방향으로 막혀 있어야** 합니다.

코일을 끄는 순간에만 전압 극성이 바뀌면서 다이오드가 순방향이 되고 전류가 흐릅니다.

## 18. 쇼트키 다이오드는 무엇이 다를까?

일반 PN 접합 다이오드와 달리 **쇼트키 다이오드(Schottky Diode)**는 금속과 반도체의 접합을 이용합니다.

대표적인 특징은 **순방향 전압이 낮고 스위칭이 빠르다**는 점입니다.

| 구분        | 일반 실리콘 다이오드   | 쇼트키 다이오드             |
| --------- | ------------- | -------------------- |
| 접합 구조     | P-N           | 금속-반도체               |
| 순방향 전압    | 약 0.6~0.7V 부근 | 약 0.2~0.4V 부근인 경우 많음 |
| 스위칭 속도    | 빠름            | 매우 빠름                |
| 역방향 누설 전류 | 비교적 작음        | 상대적으로 클 수 있음         |
| 고전압 대응    | 비교적 유리        | 상대적으로 제한될 수 있음       |

예를 들어 5A 전류가 흐른다고 가정해봅시다.

일반 다이오드의 VF가 0.7V라면,

**P = 0.7 × 5 = 3.5W**

쇼트키 다이오드의 VF가 0.3V라면,

**P = 0.3 × 5 = 1.5W**

가 됩니다.

따라서 저전압·고전류 회로에서는 순방향 전압 차이가 효율에 큰 영향을 줄 수 있습니다.

## 19. 제너 다이오드는 왜 역방향으로 사용하나?

일반적인 다이오드는 역방향 Breakdown을 피해야 합니다.

하지만 **제너 다이오드(Zener Diode)**는 특정한 역방향 전압에서 안정적으로 동작하도록 설계되어 있습니다.

예를 들어 5.1V 제너 다이오드를 생각해봅시다.

```text
역방향 전압

0V
 │
 │ 거의 전류 없음
 │
5.1V 부근
 │
 └── 전류 크게 증가
```

그래서 제너 다이오드는 일정한 전압을 유지하거나 과전압을 제한하는 데 사용할 수 있습니다.

예를 들면,

```text
12V ── 저항 ──┬── 출력
               │
             [제너]
               │
              GND
```

출력 전압이 제너 전압 부근을 넘으려 하면 제너 다이오드가 역방향으로 전류를 흘리면서 전압 상승을 제한할 수 있습니다.

실제 회로에서는 허용 전류와 전력을 반드시 고려해야 합니다.

## 20. TVS 다이오드는 순간적인 과전압을 막는다

전자회로에는 매우 짧은 순간 큰 전압이 들어오는 경우가 있습니다.

예를 들어,

* 모터 스위칭
* 자동차 전원
* 정전기
* 케이블 연결
* 낙뢰 유도 전압

등이 있습니다.

이런 순간적인 전압을 억제하기 위해 **TVS(Transient Voltage Suppressor) 다이오드**를 사용합니다.

```text
정상 전압

──────────────


과전압 발생

───────┐
       │ 큰 스파이크
       │
───────┴────────


TVS 사용

───────┐
       │ 제한
───────┴────────
```

TVS는 일정 전압 이상에서 빠르게 전류를 흘려 과전압을 제한합니다.

MOSFET이나 IC 같은 민감한 부품 보호에 자주 사용됩니다.

## 21. LED도 다이오드다

LED의 정식 명칭은 **Light Emitting Diode**, 즉 발광 다이오드입니다.

LED 역시 기본적으로 다이오드이므로 방향이 있습니다.

```text
+ ── 저항 ──>|── GND
             LED
```

순방향으로 전류가 흐르면 전자와 정공이 결합하면서 에너지가 빛으로 방출됩니다.

일반 실리콘 다이오드와 달리 LED는 재료에 따라 서로 다른 색의 빛을 냅니다.

## 22. LED의 순방향 전압은 색에 따라 다르다

LED도 순방향 전압 `VF`가 있습니다.

대략적인 예를 들면 다음과 같습니다.

| LED 색상 | 일반적인 VF 범위 예   |
| ------ | -------------- |
| 빨강     | 약 1.8~2.2V     |
| 노랑     | 약 2.0~2.2V     |
| 초록     | 종류에 따라 약 2~3V대 |
| 파랑     | 약 2.8~3.4V     |
| 흰색     | 약 2.8~3.4V     |

정확한 값은 제품과 전류에 따라 다르므로 데이터시트를 확인해야 합니다.

## 23. LED에 왜 저항을 연결해야 할까?

LED는 일반 저항처럼 전압이 올라가면 전류가 일정한 비율로 증가하지 않습니다.

순방향 전압을 넘어서면 전류가 매우 빠르게 증가할 수 있습니다.

따라서 전류 제한 없이 전원에 직접 연결하면 LED가 손상될 수 있습니다.

예를 들어,

* 전원: 5V
* 빨간 LED VF: 2V
* 원하는 전류: 10mA

라고 가정해봅시다.

저항에 걸리는 전압은

**5 - 2 = 3V**

입니다.

필요한 저항은

**R = V / I**

**R = 3 / 0.01 = 300Ω**

입니다.

따라서 300Ω 정도의 저항을 사용하면 단순 계산상 약 10mA를 흘릴 수 있습니다.

```text
5V ──[300Ω]──>|── GND
              LED
```

## 24. 다이오드의 전력 손실도 계산해야 한다

다이오드도 전류가 흐르면 열이 발생합니다.

순방향 전압이 0.7V이고 전류가 1A라면,

**P = V × I**

**P = 0.7 × 1 = 0.7W**

입니다.

전류가 5A라면,

**P = 0.7 × 5 = 3.5W**

가 됩니다.

따라서 고전류 다이오드는 발열이 상당할 수 있습니다.

이 때문에 패키지가 커지거나 방열판이 필요할 수도 있습니다.

## 25. 다이오드의 최대 전류도 중요하다

다이오드에는 흘릴 수 있는 최대 순방향 전류가 있습니다.

데이터시트에서는 흔히 `IF`와 같은 형태로 표시합니다.

예를 들어 1A 정격 다이오드에 지속적으로 5A를 흘리면 과열되어 손상될 가능성이 큽니다.

하지만 단순히 최대 전류만 확인하면 충분하지 않습니다.

실제 사용에서는,

* 평균 전류
* 순간 피크 전류
* 순방향 전압
* 접합 온도
* 주변 온도
* 방열 조건

을 함께 봐야 합니다.

## 26. 역방향 회복 시간이란 무엇일까?

다이오드가 순방향으로 전류를 흘리다가 갑자기 역방향 전압이 걸린다고 생각해봅시다.

이상적인 다이오드는 즉시 전류를 차단해야 합니다.

하지만 실제 PN 접합 다이오드는 내부에 남아 있는 전하 때문에 아주 짧은 시간 동안 역방향 전류가 흐를 수 있습니다.

```text
순방향 ON
    ↓
방향 전환
    ↓
잠깐 역방향 전류
    ↓
완전 차단
```

이 현상과 관련된 시간이 **Reverse Recovery Time**입니다.

고속 스위칭 회로에서는 이 시간이 매우 중요합니다.

다이오드가 충분히 빨리 꺼지지 않으면 손실과 발열, 전압 스파이크가 커질 수 있습니다.

## 27. 쇼트키 다이오드가 고속 스위칭에 유리한 이유

쇼트키 다이오드는 일반 PN 접합과 동작 방식이 다르기 때문에 역방향 회복 특성이 매우 빠릅니다.

그래서,

* 스위칭 전원
* DC-DC 컨버터
* 고속 디지털 회로
* 저전압 전원회로

등에서 많이 사용됩니다.

다만 낮은 순방향 전압과 빠른 속도만 보고 무조건 쇼트키를 사용할 수 있는 것은 아닙니다.

역방향 전압 정격이나 누설 전류, 온도 특성도 함께 봐야 합니다.

## 28. MOSFET 내부에도 다이오드가 있다

파워 MOSFET의 구조에는 **Body Diode**가 자연스럽게 형성됩니다.

따라서 MOSFET을 회로에서 보면 내부에 다이오드가 하나 포함된 것처럼 동작합니다.

```text
Drain
  │
 [MOSFET]
  │
Source

+ 내부 Body Diode
```

이 Body Diode는 모터 드라이버, H-Bridge, 브러시리스 ESC 같은 회로에서 매우 중요합니다.

특정 스위칭 상태에서는 모터 전류가 Body Diode를 통해 흐를 수 있습니다.

하지만 Body Diode에도 순방향 전압과 손실이 있기 때문에 고효율 회로에서는 MOSFET을 적절하게 켜서 다이오드 대신 MOSFET 채널로 전류를 흐르게 하는 방식도 사용합니다.

## 29. RC카 ESC에서는 다이오드가 어디에 관련될까?

브러시드 모터는 코일로 이루어져 있기 때문에 MOSFET을 끌 때 전류가 갑자기 사라질 수 없습니다.

따라서 전류가 흐를 경로가 필요합니다.

```text
배터리
  │
 모터
  │
MOSFET
  │
 GND
```

단순한 모터 스위칭 회로에서는 플라이백 다이오드를 사용할 수 있습니다.

브러시리스 ESC에서는 구조가 더 복잡합니다.

```text
       Battery +

    MOS     MOS     MOS
     │       │       │
     U       V       W
     │       │       │
    MOS     MOS     MOS
     │       │       │
       ─── GND ───
```

모터 코일의 전류는 MOSFET 채널과 MOSFET 내부 Body Diode 등을 통해 계속 흐를 수 있습니다.

ESC는 이 전류 흐름을 매우 빠르게 제어합니다.

따라서 MOSFET뿐 아니라 **다이오드 특성과 역방향 회복, 전압 스파이크도 고성능 ESC의 효율과 발열에 영향을 줄 수 있습니다.**

## 30. 일반 다이오드, 쇼트키, 제너, LED를 비교하면

| 종류         | 주요 특징         | 대표 용도        |
| ---------- | ------------- | ------------ |
| 일반 PN 다이오드 | 한쪽 방향 전류 통과   | 정류, 보호       |
| 고속 다이오드    | 역회복 시간이 짧음    | 고속 스위칭       |
| 쇼트키 다이오드   | 낮은 VF, 빠른 동작  | 전원, DC-DC    |
| 제너 다이오드    | 특정 역전압에서 동작   | 전압 제한, 기준 전압 |
| TVS 다이오드   | 순간 과전압 흡수     | 보호 회로        |
| LED        | 전류가 흐를 때 빛 발생 | 표시, 조명       |

같은 다이오드라는 이름을 사용하지만 목적과 특성이 서로 다릅니다.

따라서 회로에서 어떤 역할이 필요한지를 먼저 확인한 뒤 적절한 종류를 선택해야 합니다.

## 자주 헷갈리는 내용을 정리하면

| 오해                          | 바르게 이해하기                           |
| --------------------------- | ---------------------------------- |
| 다이오드는 완벽한 일방통행 스위치다         | 실제로는 순방향 전압 강하와 역방향 누설이 있음         |
| 실리콘 다이오드는 정확히 0.7V에서 켜진다    | 전압이 증가하면서 전류가 연속적으로 증가하며 0.7V는 근사값 |
| 역방향에서는 전류가 절대 0이다           | 작은 누설 전류가 존재할 수 있음                 |
| 역방향 전압은 아무리 높아도 차단한다        | Breakdown 전압을 넘으면 큰 역전류가 흐를 수 있음   |
| 쇼트키는 일반 다이오드보다 항상 좋다        | 역전압 정격과 누설 등에서는 불리할 수 있음           |
| LED는 전구의 한 종류다              | LED는 빛을 내도록 만든 다이오드                |
| LED는 5V에 바로 연결해도 된다         | 전류 제한이 필요함                         |
| 플라이백 다이오드는 평소에도 전류가 흐른다     | 평소에는 역방향이고 코일 전류를 끊을 때 동작함         |
| 제너 다이오드도 일반 다이오드처럼 순방향으로 쓴다 | 대표적인 용도는 특정 역방향 항복 특성을 이용하는 것      |
| 다이오드는 전류 방향만 보면 된다          | 전압, 전류, VF, 역전압, 발열, 속도도 중요함       |

## 핵심만 다시 정리하면

다이오드는 **P형과 N형 반도체를 접합한 PN 접합 소자**입니다.

핵심 동작은 다음과 같습니다.

```text
순방향 전압

공핍층 좁아짐
     ↓
전하 이동 쉬워짐
     ↓
전류 흐름


역방향 전압

공핍층 넓어짐
     ↓
전하 이동 어려워짐
     ↓
전류 거의 차단
```

이 특성을 이용하면 교류를 직류 방향으로 바꾸는 정류 회로를 만들 수 있고, 잘못된 극성의 전원을 차단하거나 코일에서 발생하는 역전압으로부터 트랜지스터를 보호할 수도 있습니다.

또 기본적인 PN 접합 구조를 변형하면 다양한 종류의 다이오드를 만들 수 있습니다.

```text
PN 접합
  │
  ├── 일반 다이오드
  ├── 고속 다이오드
  ├── 제너 다이오드
  ├── LED
  └── 기타 반도체 소자
```

그리고 쇼트키 다이오드는 PN 접합 대신 금속과 반도체 접합을 사용하여 낮은 순방향 전압과 빠른 스위칭 특성을 얻습니다.

다이오드의 원리를 이해하면 단순히 "전류를 한쪽으로만 흐르게 하는 부품"이라는 수준을 넘어, 왜 MOSFET의 Body Diode가 존재하는지, 왜 모터에 플라이백 다이오드가 필요한지, 왜 스위칭 전원에서 쇼트키 다이오드를 사용하는지까지 하나의 흐름으로 이해할 수 있습니다.

전자부품을 순서대로 익힌다면 **전압·전류·저항 → 다이오드 → BJT → MOSFET → 커패시터 → 인덕터 → PWM → 전원회로와 모터 제어**로 이어가면 실제 전자회로의 동작을 이해하기가 훨씬 쉬워집니다.
