# TerminalTool

TerminalTool은 여러 원격 서버의 접속 정보를 한곳에서 관리하고, SSH·TELNET 터미널과 SFTP 파일 전송을 사용할 수 있는 macOS 앱입니다.

## 시스템 요구사항

- Apple Silicon(M1 이상) Mac
- macOS 14 이상
- SSH와 SFTP는 macOS에 포함된 OpenSSH 사용
- TELNET은 시스템 또는 Homebrew를 통해 별도 설치 필요

## 설치 방법

1. `TerminalTool-0.1.0-arm64.dmg` 파일을 엽니다.
2. `TerminalTool.app`을 `Applications` 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 TerminalTool을 실행합니다.

이 앱은 개발자 서명과 Apple 공증을 사용하지 않습니다. 최초 실행이 차단되면 TerminalTool을 Control-클릭한 뒤 **열기**를 선택하거나, **시스템 설정 > 개인정보 보호 및 보안**에서 실행을 허용하세요.

## 기본 사용 방법

### 서버 등록 및 접속

1. 새 세션을 만들고 이름, 호스트, 포트, 사용자와 접속 방식을 입력합니다.
2. SSH 인증 방식으로 비밀번호, 개인 키 또는 SSH Agent를 선택합니다.
3. 필요한 경우 폴더, 태그, 즐겨찾기와 메모를 설정합니다.
4. 저장한 세션을 더블 클릭해 새 터미널 탭으로 접속합니다.

비밀번호는 일반 설정 파일이 아닌 macOS Keychain에 저장됩니다. 개인 키는 앱에 복사하지 않고 사용자가 지정한 파일을 참조합니다.

### 세션 찾기와 작업 공간

- 세션 이름, 호스트, 사용자, 폴더, 태그와 메모로 검색할 수 있습니다.
- 여러 연결을 탭으로 열어 전환할 수 있습니다.
- 탭을 창 밖으로 드래그하거나 `⌘⇧N`을 사용해 별도 창으로 분리할 수 있습니다.

### SFTP 파일 관리

1. SSH 세션에서 SFTP 기능을 열면 해당 서버의 파일 창이 표시됩니다.
2. 원격 폴더를 펼쳐 이동하고 파일을 선택합니다.
3. Finder의 파일을 끌어 놓아 업로드하거나 원격 파일을 Finder로 끌어 다운로드합니다.
4. 원격 텍스트 파일을 편집하거나 이미지와 PDF를 미리 볼 수 있습니다.

현재는 파일 단위 전송만 지원하며 폴더 재귀 전송, 다중 전송 큐와 중단 후 재개는 지원하지 않습니다.

### Jump Host와 포트 포워딩

- 베스천 서버를 별도 프로필로 등록한 뒤 여러 SSH 세션에서 재사용할 수 있습니다.
- 로컬, 원격 및 동적 SOCKS 포트 포워딩을 세션에 설정할 수 있습니다.

이 기능들은 사용 환경에 따라 서버 측 SSH 설정과 네트워크 방화벽 설정이 필요할 수 있습니다.

## 보안 안내

- 처음 접속하는 서버의 호스트 키 지문을 직접 확인하세요.
- 호스트 키가 변경되면 서버 관리자에게 확인하기 전까지 접속하지 마세요.
- TELNET은 통신 내용을 암호화하지 않으므로 신뢰할 수 있는 제한된 환경에서만 사용하세요.
- 세션 정보와 Keychain 자격증명은 다른 Mac으로 자동 이전되지 않습니다.
