PWM(Pulse Width Modulation)은 전자회로에서 매우 자주 사용하는 제어 방식입니다.

우리말로는 **펄스 폭 변조**라고 부릅니다.

가장 단순하게 설명하면 **전원을 계속 조금만 주는 대신, 완전히 켰다 껐다를 매우 빠르게 반복하고 ON 상태의 시간을 조절하여 평균적인 출력을 바꾸는 방법**입니다.

예를 들어 12V 모터를 절반 정도의 출력으로 돌리고 싶다고 생각해봅시다.

직관적으로는 12V를 6V로 낮춰 공급하면 될 것처럼 보입니다.

하지만 전압을 선형적으로 낮추는 방식은 제어 소자에서 많은 열을 발생시킬 수 있습니다.

PWM은 다르게 접근합니다.

```text
12V를 계속 절반으로 낮춤
→ 6V를 계속 공급


PWM 방식
→ 12V ON
→ 0V OFF
→ 빠르게 반복
```

ON과 OFF를 충분히 빠르게 반복하면 모터나 LED 같은 부하는 그 평균적인 효과를 받아 중간 출력처럼 동작할 수 있습니다.

이 글에서는 PWM의 기본 개념부터 듀티비, 주파수, 평균 전압, MOSFET과의 관계, 모터와 ESC에서의 실제 동작까지 살펴봅니다.

## 먼저 PWM을 한눈에 보기

| 항목        | 내용                        |
| --------- | ------------------------- |
| 정식 명칭     | Pulse Width Modulation    |
| 우리말       | 펄스 폭 변조                   |
| 핵심 원리     | ON/OFF 시간을 조절해 평균 출력 제어   |
| 주요 변수     | Duty Cycle, Frequency     |
| 대표 스위칭 소자 | MOSFET                    |
| 주요 용도     | 모터 속도, LED 밝기, 전원 변환, ESC |
| 장점        | 높은 효율, 빠른 제어              |
| 주의점       | 스위칭 손실, EMI, 발열, 주파수 선택   |

PWM에서 가장 중요한 두 가지는 **듀티비(Duty Cycle)**와 **주파수(Frequency)**입니다.

## 1. PWM은 전원을 빠르게 켰다 끄는 방식이다

가장 단순한 PWM 신호를 보면 다음과 같습니다.

```text
ON    OFF    ON    OFF

████______████______████______
```

전압이 12V라면,

```text
12V ──████______████______████
 0V ──────────────────────────
```

처럼 12V와 0V를 빠르게 반복합니다.

중요한 점은 중간 전압을 직접 만드는 것이 아니라 **전압을 ON 또는 OFF 상태로 빠르게 바꾼다**는 것입니다.

## 2. 듀티비는 무엇일까?

PWM 한 주기에서 ON 상태가 차지하는 비율을 **Duty Cycle**이라고 합니다.

예를 들어 한 주기가 10ms라고 생각해봅시다.

그중 5ms 동안 ON이고 5ms 동안 OFF라면,

**Duty Cycle = 50%**

입니다.

```text
한 주기

|<------ 10ms ------>|

██████████__________

ON 5ms    OFF 5ms
```

듀티비는 다음과 같이 계산할 수 있습니다.

**Duty Cycle = TON / T × 100%**

* TON: ON 시간
* T: 전체 주기

## 3. 듀티비가 바뀌면 무엇이 달라질까?

25% 듀티비라면,

```text
██______██______██______
```

50%라면,

```text
████____████____████____
```

75%라면,

```text
██████__██████__██████__
```

100%라면,

```text
████████████████████████
```

입니다.

즉 듀티비가 커질수록 한 주기 동안 전원이 켜져 있는 시간이 길어집니다.

## 4. 평균 전압은 어떻게 달라질까?

이상적으로 12V PWM을 생각해봅시다.

듀티비가 50%라면 평균값은 단순 계산으로,

**12V × 0.5 = 6V**

입니다.

25%라면,

**12V × 0.25 = 3V**

75%라면,

**12V × 0.75 = 9V**

입니다.

| 듀티비  | 평균 전압 예 |
| ---- | ------: |
| 0%   |      0V |
| 25%  |      3V |
| 50%  |      6V |
| 75%  |      9V |
| 100% |     12V |

하지만 여기서 중요한 점이 있습니다.

**실제로 출력이 계속 6V인 것은 아닙니다.**

50% PWM에서도 순간 전압은 여전히 12V와 0V를 반복합니다.

```text
순간 전압

12V ████____████____████____
 0V


평균적으로 보면

약 6V 효과
```

따라서 PWM의 평균값과 실제 순간 파형은 구분해야 합니다.

## 5. 왜 평균값으로 동작하는 것처럼 보일까?

부하에 따라 PWM을 받아들이는 방식이 다릅니다.

예를 들어 모터는 내부에 코일이 있고 회전자의 관성도 있습니다.

그래서 전압이 잠깐 OFF되었다고 해서 전류와 회전 속도가 즉시 0이 되지 않습니다.

```text
PWM 전압

████____████____████____


모터 전류

 /¯\__/¯\__/¯\__/¯\__


모터 회전

──────── 비교적 부드러움 ────────
```

LED의 경우 사람의 눈이 빠른 깜빡임을 개별적으로 구분하지 못하면 평균적인 밝기로 느낍니다.

즉 PWM은 **부하의 전기적·기계적 특성 또는 사람의 감각이 빠른 ON/OFF를 평균화하는 효과**를 이용합니다.

## 6. 50% PWM은 진짜 6V와 같은가?

완전히 같지는 않습니다.

12V를 50% 듀티로 공급하면 순간적으로는 12V가 그대로 들어갑니다.

```text
PWM 50%

12V ████____████____
```

반면 실제 6V DC라면,

```text
6V ─────────────────
```

입니다.

두 신호의 평균값은 비슷할 수 있지만 부하에 미치는 영향은 다를 수 있습니다.

예를 들어 저항, 모터, LED, 히터처럼 부하 특성에 따라 전류와 발열 특성이 달라질 수 있습니다.

따라서 **PWM 50% = 모든 면에서 6V DC와 동일하다**고 이해하면 안 됩니다.

## 7. 저항 부하에서는 전력 계산도 주의해야 한다

12V를 10Ω 저항에 계속 공급하면,

**P = V² / R**

이므로,

**P = 12² / 10 = 14.4W**

입니다.

50% PWM에서는 절반의 시간 동안 14.4W가 발생하고 나머지 절반은 0W입니다.

평균 전력은 이상적으로 약,

**14.4 × 0.5 = 7.2W**

입니다.

그런데 평균 전압 6V를 저항에 계속 걸면,

**P = 6² / 10 = 3.6W**

입니다.

즉 결과가 다릅니다.

이것은 저항의 전력이 전압에 대해 제곱 관계를 가지기 때문입니다.

따라서 PWM에서는 단순한 평균 전압만 보고 모든 전력 관계를 계산하면 안 됩니다.

## 8. PWM의 또 다른 핵심은 주파수다

PWM이 1초에 몇 번 반복되는지를 **Frequency**, 주파수라고 합니다.

단위는 Hz입니다.

예를 들어,

* 1kHz = 초당 1,000주기
* 10kHz = 초당 10,000주기
* 20kHz = 초당 20,000주기

입니다.

PWM 주파수가 20kHz라면 한 주기 시간은,

**T = 1 / f**

이므로,

**T = 1 / 20,000 = 0.00005초**

즉 **50μs**입니다.

## 9. 주기와 주파수의 관계

주파수와 주기는 서로 반대 관계입니다.

**f = 1 / T**

**T = 1 / f**

입니다.

예를 들어,

| 주파수    |  한 주기 |
| ------ | ----: |
| 100Hz  |  10ms |
| 1kHz   |   1ms |
| 10kHz  | 100μs |
| 20kHz  |  50μs |
| 100kHz |  10μs |

주파수가 높을수록 한 번의 ON/OFF 주기가 짧아집니다.

## 10. PWM 주파수가 너무 낮으면?

LED를 매우 낮은 주파수로 PWM하면 사람의 눈에 깜빡임이 보일 수 있습니다.

```text
낮은 주파수

ON       OFF       ON

████________████________
```

모터에서도 토크 변동이 크게 느껴질 수 있고 귀에 들리는 소음이 발생할 수 있습니다.

특히 PWM 주파수가 가청 주파수 영역에 있으면 모터 코일이나 기계 구조에서 소리가 날 수 있습니다.

## 11. 주파수를 높이면 더 부드러워질 수 있다

주파수가 높아지면 ON/OFF 간격이 짧아집니다.

모터의 인덕턴스 때문에 한 주기 동안 전류가 크게 변하지 못합니다.

```text
낮은 주파수

전류
/¯¯\____/¯¯\____/¯¯\


높은 주파수

전류
/\/\/\/\/\/\/\/\/\/\
```

주파수가 높을수록 전류 리플이 작아질 수 있습니다.

그래서 모터가 더 부드럽게 동작할 수 있습니다.

## 12. 그렇다면 주파수는 높을수록 무조건 좋을까?

그렇지 않습니다.

PWM 주파수를 높이면 MOSFET이 더 자주 켜지고 꺼져야 합니다.

예를 들어,

```text
8kHz
→ 초당 8,000번 스위칭


32kHz
→ 초당 32,000번 스위칭
```

한 번의 스위칭마다 작은 손실이 발생합니다.

따라서 주파수가 높아질수록 **스위칭 손실이 증가할 수 있습니다.**

## 13. MOSFET이 PWM에 잘 맞는 이유

기계식 릴레이로 PWM을 해보려고 생각해봅시다.

```text
딸깍 딸깍 딸깍 딸깍...
```

릴레이는 기계적으로 접점이 움직이기 때문에 매우 빠른 PWM에는 적합하지 않습니다.

반면 MOSFET은 기계적으로 움직이는 부분이 없습니다.

```text
Gate
 ↓
MOSFET ON

Gate
 ↓
MOSFET OFF
```

수 kHz에서 수백 kHz 이상까지 매우 빠른 스위칭이 가능합니다.

그래서 PWM 회로에서는 MOSFET이 매우 많이 사용됩니다.

## 14. MOSFET을 왜 완전히 ON/OFF할까?

MOSFET으로 모터 출력을 50%로 만들고 싶다고 생각해봅시다.

MOSFET을 중간 정도만 켜서 전압을 떨어뜨릴 수도 있습니다.

하지만 이 경우 MOSFET에서 큰 전력 손실이 발생할 수 있습니다.

예를 들어,

* MOSFET 양단 전압 6V
* 전류 10A

라면,

**P = V × I**

**P = 6 × 10 = 60W**

가 됩니다.

60W가 MOSFET에서 열로 변합니다.

## 15. PWM은 MOSFET 손실을 줄일 수 있다

MOSFET이 완전히 OFF이면,

```text
전류 ≈ 0
P ≈ 0
```

입니다.

완전히 ON되면 RDS(on)이 매우 작으므로 전압 강하도 작습니다.

```text
전류 큼
전압 강하 작음
P 비교적 작음
```

그래서 대부분의 시간을 ON 또는 OFF 상태로 유지하면 효율을 높일 수 있습니다.

```text
OFF     ON      OFF      ON

──── ███████ ──── ███████
```

이것이 PWM과 MOSFET의 조합이 매우 효율적인 이유입니다.

## 16. 하지만 ON/OFF 전환 순간에는 손실이 있다

MOSFET은 실제로 0초 만에 완전히 ON 또는 OFF되지 않습니다.

전환하는 아주 짧은 시간 동안,

* MOSFET 양단 전압도 존재하고
* 상당한 전류도 흐릅니다.

```text
OFF
 ↓
중간 상태
 ↓
ON
```

이때,

**P = V × I**

에 의해 큰 순간 전력 손실이 발생할 수 있습니다.

이를 **스위칭 손실(Switching Loss)**이라고 합니다.

## 17. 주파수가 높으면 스위칭 손실이 늘어나는 이유

한 번의 스위칭에서 일정한 에너지 손실이 생긴다고 생각해봅시다.

초당 10,000번 스위칭할 때보다 초당 100,000번 스위칭하면 손실이 발생하는 횟수도 많아집니다.

```text
낮은 주파수

ON ─ OFF ─ ON ─ OFF


높은 주파수

ON/OFF/ON/OFF/ON/OFF/ON/OFF
```

따라서 PWM 주파수를 높이면 제어 품질이 좋아지는 부분도 있지만 MOSFET 발열과 효율에서는 불리할 수 있습니다.

## 18. PWM으로 LED 밝기를 조절할 수 있다

LED에 PWM을 적용해봅시다.

```text
전원
 │
MOSFET
 │
LED
 │
GND
```

듀티비가 10%라면,

```text
█_________█_________█_________
```

LED가 짧은 시간만 켜집니다.

90%라면,

```text
█████████_█████████_█████████_
```

대부분의 시간 동안 켜집니다.

주파수가 충분히 높으면 사람 눈에는 깜빡임 대신 밝기 차이로 보입니다.

## 19. 왜 LED 전압을 낮추는 것보다 PWM을 사용할까?

LED는 전압과 전류 관계가 선형적이지 않습니다.

따라서 단순히 전압만 낮춰 밝기를 조절하는 방식은 제어가 쉽지 않습니다.

일정한 적절한 전류를 흘리는 ON 상태를 만들고 PWM으로 켜지는 시간을 조절하면 밝기를 비교적 안정적으로 제어할 수 있습니다.

고출력 LED에서는 전류 제어 회로와 PWM을 함께 사용하는 경우가 많습니다.

## 20. DC 모터 속도도 PWM으로 조절할 수 있다

브러시드 DC 모터에 MOSFET을 연결했다고 생각해봅시다.

```text
+12V
  │
[모터]
  │
MOSFET
  │
 GND
```

MOSFET을 PWM으로 제어합니다.

25% 듀티라면,

```text
██______██______██______
```

75%라면,

```text
██████__██████__██████__
```

모터에 전달되는 평균적인 에너지가 달라져 속도와 토크가 달라집니다.

## 21. 모터에는 왜 PWM 전류가 그대로 네모 모양이 아닐까?

모터 권선은 인덕터입니다.

인덕터의 핵심 공식은,

**V = L × di/dt**

입니다.

즉 전류는 순간적으로 변할 수 없습니다.

전압을 PWM으로 네모 형태로 넣더라도,

```text
전압

████____████____████____
```

실제 권선 전류는 더 부드럽게 변화합니다.

```text
전류

 /¯\__/¯\__/¯\__/¯\__
```

이 때문에 PWM으로 모터를 안정적으로 제어할 수 있습니다.

## 22. PWM OFF 순간에도 전류는 흐르려고 한다

MOSFET이 ON인 동안 모터 코일에 전류가 흐릅니다.

```text
배터리
 ↓
모터 권선
 ↓
MOSFET
 ↓
GND
```

MOSFET을 OFF해도 인덕터 성질 때문에 전류가 즉시 0이 되지 않습니다.

따라서 전류가 계속 흐를 경로가 필요합니다.

```text
MOSFET OFF
     ↓
모터 전류 계속 흐르려 함
     ↓
플라이백 다이오드
또는 다른 MOSFET 경로 사용
```

그래서 PWM 모터 드라이버에서는 MOSFET과 다이오드가 함께 매우 중요합니다.

## 23. 브러시드 모터를 양방향으로 돌리려면?

MOSFET 하나로는 보통 한 방향 제어가 기본입니다.

정회전과 역회전을 모두 하려면 **H-Bridge**를 사용할 수 있습니다.

```text
        +V

     MOS     MOS
      │       │
      └─ Motor┘
      │       │
     MOS     MOS

       GND
```

네 개의 스위치를 적절한 조합으로 켜면 모터 전류 방향을 바꿀 수 있습니다.

```text
정회전

+ → Motor → -


역회전

- ← Motor ← +
```

각 MOSFET을 PWM으로 제어하면 방향뿐 아니라 속도도 조절할 수 있습니다.

## 24. 브러시리스 모터에서는 PWM이 더 복잡하다

브러시리스 모터에는 보통 U, V, W 세 상이 있습니다.

```text
ESC
 │
 ├── U
 ├── V
 └── W
      │
   BLDC Motor
```

각 상을 제어하기 위해 기본적으로 6개의 MOSFET 스위칭 위치를 사용합니다.

```text
             Battery +

        MOS     MOS     MOS
         │       │       │
         U       V       W
         │       │       │
        MOS     MOS     MOS
         │       │       │
             GND
```

ESC는 이 MOSFET들을 정해진 순서와 PWM 듀티로 제어합니다.

## 25. 브러시리스 ESC에서 PWM은 무엇을 조절할까?

ESC는 단순히 배터리 전압을 낮춰서 모터 속도를 조절하지 않습니다.

각 모터 상에 배터리 전압을 빠르게 연결하고 끊으면서 전류를 제어합니다.

```text
배터리
  ↓
MOSFET PWM
  ↓
U/V/W 권선 전류
  ↓
자기장
  ↓
로터 회전
```

즉 ESC가 궁극적으로 제어하려는 것은 **모터 권선의 전류와 그로 인해 만들어지는 토크**입니다.

## 26. ESC에서 50% 스로틀은 반드시 50% PWM일까?

꼭 그렇지는 않습니다.

송신기의 50% 스로틀 입력이 ESC 내부에서 정확히 50% Duty Cycle로 변환된다고 단정할 수 없습니다.

ESC 내부에서는,

* 스로틀 맵
* 모터 회전수
* 전류 제한
* 타이밍
* 부스트
* 터보
* 센서 정보

등을 이용해 실제 MOSFET 제어를 결정할 수 있습니다.

따라서 사용자가 느끼는 스로틀 비율과 실제 PWM 듀티는 서로 다를 수 있습니다.

## 27. PWM과 모터 회전 속도는 정확히 비례할까?

이상적인 조건에서는 듀티비가 높아질수록 평균적인 모터 전압과 속도가 증가하는 경향이 있습니다.

하지만 실제 모터에는,

* 권선 저항
* 인덕턴스
* 역기전력
* 부하
* 마찰
* ESC 손실

등이 있습니다.

그래서,

```text
Duty 50%
→ RPM도 정확히 50%
```

라고 단순하게 볼 수는 없습니다.

## 28. 역기전력과 PWM은 어떻게 연결될까?

모터가 회전하면 역기전력이 발생합니다.

모터가 빠르게 돌수록 역기전력이 커지는 경향이 있습니다.

단순하게 보면 모터 전류는,

**I ≈ (공급전압 - 역기전력) / 권선저항**

의 영향을 받습니다.

모터가 정지해 있을 때는 역기전력이 거의 없기 때문에 큰 전류가 흐를 수 있습니다.

```text
정지

Back EMF ≈ 0
↓
전류 큼


고속 회전

Back EMF 큼
↓
전류 감소
```

PWM은 이 전류를 빠르게 조절하는 역할을 합니다.

## 29. 저속에서 모터가 더 뜨거워질 수도 있는 이유

저속이라고 항상 전류가 작은 것은 아닙니다.

예를 들어 자동차가 강한 부하를 받으면서 낮은 속도로 움직이고 있다면 모터 회전 속도가 낮아 역기전력이 작고 상당한 전류가 필요할 수 있습니다.

```text
낮은 RPM
+
큰 부하
+
높은 토크 요구
      ↓
큰 전류
      ↓
모터 발열
```

따라서 RC카에서 저속으로 강하게 버티는 상황이 모터에 상당한 열을 발생시킬 수 있습니다.

## 30. PWM 주파수가 모터 소리에 영향을 줄 수 있다

사람이 들을 수 있는 주파수 범위는 대략 수십 Hz에서 20kHz 부근까지입니다.

PWM 주파수가 가청 영역에 있으면 모터 권선이나 기계 구조가 진동하면서 소리가 날 수 있습니다.

```text
8kHz PWM
→ 8kHz 부근 소리가 들릴 수 있음


24kHz PWM
→ 가청 영역 위쪽 또는 밖으로 이동
```

실제 소리는 PWM 기본 주파수뿐 아니라 고조파, 모터 구조, 부하 등에 따라서도 달라집니다.

## 31. 높은 PWM 주파수가 모터에 항상 시원한 것은 아니다

높은 PWM 주파수에서는 전류 리플이 감소할 수 있습니다.

하지만 ESC의 MOSFET은 더 자주 스위칭합니다.

또 모터 철심과 권선에서도 주파수와 관련된 손실이 발생할 수 있습니다.

따라서 주파수 변경은,

```text
모터 부드러움
   ↕
ESC 발열
   ↕
모터 발열
   ↕
효율
   ↕
소음
```

사이의 균형 문제입니다.

## 32. PWM과 커패시터는 어떻게 연결될까?

PWM 회로에서는 전류 요구량이 빠르게 변합니다.

```text
전류

높음 ████____████____
낮음
```

전원선에는 저항과 인덕턴스가 있기 때문에 이 빠른 변화가 전압 리플과 스파이크를 만들 수 있습니다.

그래서 MOSFET 근처에 커패시터를 배치합니다.

```text
배터리 ──────── ESC
               │
              [C]
               │
              GND
```

커패시터는 순간적으로 전류를 공급하거나 흡수해 입력 전압 변화를 줄이는 데 도움을 줍니다.

## 33. PWM과 인덕터는 어떻게 연결될까?

인덕터는 전류 변화를 완화합니다.

그래서 DC-DC 컨버터에서는 PWM과 인덕터를 함께 사용합니다.

```text
입력
 │
MOSFET PWM
 │
[ L ]
 │
 ├── 출력
 │
[C]
 │
GND
```

MOSFET의 네모난 PWM 전압을 인덕터와 커패시터가 부드러운 DC 전압으로 바꾸는 역할을 합니다.

## 34. Buck Converter에서도 PWM을 사용한다

12V를 5V로 낮추는 Buck Converter를 생각해봅시다.

MOSFET을 PWM으로 켰다 끕니다.

```text
12V
 │
MOSFET
 │
[인덕터]
 │
 ├── 5V
 │
[C]
 │
GND
```

MOSFET ON:

```text
입력
 ↓
인덕터에 에너지 저장
 ↓
부하 공급
```

MOSFET OFF:

```text
인덕터
 ↓
저장 에너지 계속 공급
 ↓
부하
```

이 과정을 반복하여 출력 전압을 조절합니다.

## 35. 듀티비로 출력 전압을 제어할 수 있다

이상적인 Buck Converter의 단순한 경우,

**Vout ≈ Vin × Duty**

로 생각할 수 있습니다.

예를 들어,

* Vin = 12V
* Duty = 50%

라면,

**Vout ≈ 6V**

입니다.

실제 회로에서는 손실과 제어 방식 때문에 차이가 있지만 PWM으로 전압을 변환할 수 있다는 기본 원리를 보여줍니다.

## 36. PWM은 디지털인가 아날로그인가?

PWM 신호 자체는 두 상태만 가집니다.

```text
HIGH
LOW
```

이 점에서는 디지털 신호처럼 보입니다.

하지만 듀티비를 조절하면 평균적인 출력값을 연속적으로 변화시킬 수 있습니다.

```text
10%
20%
30%
40%
...
90%
```

그래서 디지털 출력으로 아날로그와 비슷한 효과를 만드는 데 많이 사용됩니다.

## 37. MCU에서 PWM은 어떻게 만들까?

마이크로컨트롤러에는 보통 Timer가 있습니다.

Timer가 일정한 속도로 숫자를 증가시키고 특정 값과 비교해 출력을 HIGH와 LOW로 바꿀 수 있습니다.

예를 들어 0부터 999까지 세는 타이머가 있다고 생각해봅시다.

```text
0 ─────────────────── 999
```

비교값이 500이면,

```text
0 ~ 499
→ HIGH

500 ~ 999
→ LOW
```

가 되어 약 50% Duty의 PWM을 만들 수 있습니다.

비교값을 250으로 바꾸면 약 25%가 됩니다.

## 38. PWM 해상도란 무엇일까?

8비트 PWM이라면 보통 0~255 범위의 값을 사용할 수 있습니다.

즉 약 256단계입니다.

```text
0
1
2
3
...
255
```

10비트라면 0~1023, 즉 약 1,024단계를 만들 수 있습니다.

비트 수가 높을수록 듀티비를 더 세밀하게 조절할 수 있습니다.

## 39. 주파수와 해상도는 서로 영향을 줄 수 있다

마이크로컨트롤러의 타이머 클럭은 제한되어 있습니다.

예를 들어 타이머가 한 주기를 만들기 위해 더 많은 카운트 값을 사용하면 PWM 해상도는 좋아지지만 한 주기를 완료하는 데 시간이 더 걸립니다.

따라서 같은 클럭에서는 일반적으로,

```text
높은 PWM 주파수
→ 사용할 수 있는 카운트 감소
→ 해상도 감소 가능


높은 해상도
→ 카운트 증가
→ 주파수 감소 가능
```

와 같은 관계가 생길 수 있습니다.

## 40. PWM에는 Dead Time이 왜 필요할까?

H-Bridge나 3상 인버터에서는 위쪽과 아래쪽 MOSFET이 있습니다.

```text
+V
 │
MOSFET High
 │
출력
 │
MOSFET Low
 │
GND
```

만약 두 MOSFET이 동시에 켜지면,

```text
+V
 ↓
MOSFET
 ↓
MOSFET
 ↓
GND
```

전원과 GND가 거의 직접 연결됩니다.

이를 **Shoot-Through**라고 합니다.

매우 큰 전류가 흘러 MOSFET이 손상될 수 있습니다.

## 41. Dead Time은 두 MOSFET을 잠깐 모두 끄는 시간이다

High-Side MOSFET을 끈 직후 Low-Side MOSFET을 바로 켜지 않고 아주 짧은 시간을 기다립니다.

```text
High MOSFET

ON────OFF────────


Low MOSFET

────────OFF──ON──
          ↑
       Dead Time
```

이 시간을 **Dead Time**이라고 합니다.

MOSFET이 완전히 꺼질 시간을 확보하여 Shoot-Through를 방지합니다.

## 42. Dead Time이 너무 길어도 좋지 않다

Dead Time이 너무 짧으면 두 MOSFET이 겹쳐 켜질 위험이 있습니다.

하지만 너무 길면 그 시간 동안 MOSFET 채널 대신 Body Diode 등을 통해 전류가 흐를 수 있습니다.

그러면 손실이 증가할 수 있습니다.

따라서,

```text
Dead Time 너무 짧음
→ Shoot-Through 위험


Dead Time 너무 김
→ 효율 저하
```

이므로 적절한 조정이 필요합니다.

## 43. ESC에서 MOSFET 제어가 어려운 이유

RC카 ESC는 단순한 PWM 발생기가 아닙니다.

내부에서는,

* MOSFET 게이트 제어
* Dead Time
* 모터 위치 판단
* 상 전환
* PWM
* 전류 제한
* 과전압 보호
* 온도 보호
* 타이밍 제어

등이 동시에 이루어집니다.

```text
MCU
 │
Gate Driver
 │
MOSFET 6개 이상
 │
U / V / W
 │
모터
```

따라서 ESC의 성능은 단순히 MOSFET 사양 하나로 결정되지 않습니다.

## 44. 센서드 브러시리스 모터에서는 PWM을 어떻게 사용할까?

센서드 모터에는 로터 위치를 알려주는 센서가 있습니다.

ESC가 로터 위치를 확인합니다.

```text
로터 위치 센서
      ↓
     ESC
      ↓
어떤 상을 켤지 결정
      ↓
PWM으로 전류 제어
```

저속에서도 로터 위치를 알고 있기 때문에 각 상을 더 정확한 타이밍에 제어할 수 있습니다.

RC 투어링에서 센서드 시스템을 많이 사용하는 이유 중 하나입니다.

## 45. PWM과 ESC의 Boost/Turbo는 같은 것일까?

완전히 같은 개념은 아닙니다.

기본적인 출력 조절에는 PWM이 사용되지만 센서드 RC ESC에서 Boost와 Turbo라고 부르는 기능은 보통 **모터 전기적 타이밍을 변화시키는 기능**과 관련됩니다.

```text
PWM
→ 평균적인 권선 전류/출력 제어


Boost / Turbo
→ 모터 구동 타이밍 변화
```

서로 함께 동작할 수 있지만 같은 기능은 아닙니다.

## 46. PWM이 배터리 전압 자체를 낮추는 것은 아니다

2S LiPo 배터리를 사용하면 대략 7~8V대의 전압이 ESC에 들어옵니다.

스로틀을 절반만 줬다고 배터리 전압 자체가 절반으로 변하는 것은 아닙니다.

```text
배터리

7.6V
 │
ESC
 │
PWM
 │
모터
```

MOSFET이 배터리 전압을 모터에 연결하는 시간을 조절합니다.

따라서 모터 단자에서는 매우 빠른 펄스 형태의 전압을 볼 수 있습니다.

## 47. 오실로스코프로 보면 PWM은 어떻게 보일까?

멀티미터로 PWM을 측정하면 평균값이나 계측기의 방식에 따른 값만 보일 수 있습니다.

하지만 오실로스코프로 보면 실제 파형을 확인할 수 있습니다.

```text
전압
 ↑
 │   ┌────┐      ┌────┐
 │   │    │      │    │
 │───┘    └──────┘    └────
 │
 └──────────────────────→ 시간
```

여기서,

* 높이 = 전압
* 펄스 폭 = ON 시간
* 반복 간격 = 주기

를 직접 확인할 수 있습니다.

## 48. PWM의 장점과 단점을 정리하면

| 장점                 | 단점                      |
| ------------------ | ----------------------- |
| 높은 효율              | 스위칭 손실 발생               |
| MOSFET과 잘 맞음       | EMI 발생 가능               |
| 세밀한 출력 조절          | 주파수 선택 필요               |
| MCU에서 생성하기 쉬움      | 게이트 드라이버 설계 중요          |
| 모터·LED·전원회로에 활용 가능 | 배선과 PCB 설계에 영향 받음       |
| 발열을 줄일 수 있음        | 너무 높은 주파수는 오히려 발열 증가 가능 |

## 자주 헷갈리는 내용을 정리하면

| 오해                           | 바르게 이해하기                      |
| ---------------------------- | ----------------------------- |
| 50% PWM은 실제 6V DC와 완전히 같다    | 12V와 0V를 반복하며 평균 효과만 비슷할 수 있음 |
| PWM은 전압 자체를 낮춘다              | 전압을 연결하는 시간을 조절함              |
| 듀티비만 알면 PWM을 모두 알 수 있다       | 주파수도 매우 중요함                   |
| 주파수가 높을수록 무조건 좋다             | 스위칭 손실과 발열이 증가할 수 있음          |
| PWM에서는 MOSFET 발열이 전혀 없다      | RDS(on) 손실과 스위칭 손실이 존재함       |
| 모터 전류도 PWM 전압처럼 네모 파형이다      | 권선 인덕턴스 때문에 더 부드럽게 변화함        |
| 50% 스로틀이면 ESC Duty도 정확히 50%다 | ESC 제어 로직에 따라 다를 수 있음         |
| PWM Duty와 모터 RPM은 정확히 비례한다   | 부하, 역기전력, 손실 등에 따라 달라짐        |
| Dead Time은 길수록 안전하다          | 너무 길면 손실이 증가할 수 있음            |
| Boost와 Turbo는 PWM을 높이는 기능이다  | 보통 모터 타이밍 제어와 관련됨             |
| PWM은 모터 속도에만 사용한다            | LED, 전원 변환, 히터 등 다양한 곳에 사용함   |

## 핵심만 다시 정리하면

PWM은 **전원을 빠르게 ON/OFF하면서 ON 상태가 차지하는 시간을 바꾸어 평균적인 출력을 제어하는 방식**입니다.

가장 중요한 값은 듀티비입니다.

**Duty Cycle = TON / T × 100%**

예를 들어 12V PWM에서,

```text
25%

██______██______

평균 효과 작음


50%

████____████____

중간


100%

████████████████

항상 ON
```

처럼 듀티비에 따라 부하에 전달되는 평균적인 에너지가 달라집니다.

PWM이 효율적인 이유는 MOSFET을 중간 상태에 오래 두는 대신 대부분의 시간을 **완전 ON 또는 완전 OFF** 상태로 사용하기 때문입니다.

```text
선형 제어

MOSFET을 반쯤 ON
      ↓
전압과 전류가 동시에 존재
      ↓
큰 발열


PWM

완전 ON ↔ 완전 OFF
      ↓
손실 감소
```

하지만 실제 MOSFET은 ON/OFF 전환에 시간이 필요하기 때문에 스위칭 손실이 발생합니다.

그래서 PWM 주파수를 높이면 모터 전류가 부드러워지는 장점이 있지만 MOSFET 발열은 증가할 수 있습니다.

또 모터 권선은 인덕터이기 때문에 PWM 전압이 OFF된 순간에도 전류는 계속 흐르려고 합니다.

```text
MOSFET ON
   ↓
모터 코일에 에너지 저장


MOSFET OFF
   ↓
코일 전류 계속 흐르려 함
   ↓
다이오드 또는 다른 MOSFET 경로
```

그리고 ESC 입력에서는 커패시터가 빠른 전류 변화로 인한 전압 흔들림을 완화합니다.

결국 지금까지 살펴본 부품은 PWM 회로 안에서 다음처럼 연결됩니다.

```text
배터리
   │
커패시터
   │
MOSFET
   │
PWM
   │
인덕터 / 모터 권선
   │
다이오드 / 다른 MOSFET
   │
전류 순환
```

즉 PWM을 이해하면 MOSFET, 다이오드, 커패시터, 인덕터를 각각 따로 배우던 단계에서 벗어나 **이 부품들이 실제 전자회로에서 어떻게 함께 움직이는지** 이해할 수 있습니다.

RC카 ESC는 바로 이 원리를 매우 빠르고 정밀하게 수행하는 장치입니다.
