커패시터(Capacitor)는 전자회로에서 저항, 다이오드, 트랜지스터만큼 자주 등장하는 기본 부품입니다.

한국에서는 오래전부터 **콘덴서**라고도 많이 부릅니다.

가장 단순하게 설명하면 커패시터는 **두 도체 사이에 전하를 분리하여 저장하고, 전압이 갑자기 변하려는 것을 완화하는 부품**입니다.

배터리처럼 오랫동안 많은 에너지를 저장하는 장치는 아니지만, 아주 짧은 시간 동안 전하를 빠르게 충전하고 방전할 수 있기 때문에 전원 안정화, 노이즈 제거, 신호 필터링, 타이밍 회로, 모터 제어 등 거의 모든 전자회로에서 사용됩니다.

이 글에서는 커패시터의 기본 구조와 충전·방전 원리부터 시작해 RC 시정수, 직류와 교류에서의 동작 차이, 디커플링과 ESC에서의 역할까지 살펴봅니다.

## 먼저 커패시터를 한눈에 보기

| 항목       | 내용                          |
| -------- | --------------------------- |
| 기본 구조    | 두 도체판 + 절연체                 |
| 저장하는 것   | 전기적으로 분리된 전하와 전기장 에너지       |
| 기본 물리량   | 정전용량 C                      |
| 단위       | 패럿(F)                       |
| 직류 정상 상태 | 이상적으로 전류가 흐르지 않음            |
| 전압이 변할 때 | 충전·방전 전류가 흐름                |
| 주요 역할    | 전원 안정화, 필터링, 타이밍, 에너지 임시 저장 |
| 주요 종류    | 세라믹, 전해, 필름, 탄탈 등           |

커패시터의 핵심은 **전압 변화에 반응한다**는 것입니다.

저항이 전류를 제한하는 부품이라면, 커패시터는 **전압이 갑자기 변하는 것을 싫어하는 부품**이라고 생각하면 이해하기 쉽습니다.

## 1. 커패시터는 어떻게 생겼을까?

가장 기본적인 커패시터는 두 개의 도체판 사이에 절연체를 넣은 구조입니다.

```text
도체판        절연체        도체판

██████       |||||        ██████
  │                         │
  A                         B
```

두 금속판은 서로 직접 연결되어 있지 않습니다.

중간에는 전류가 쉽게 흐르지 않는 절연체가 있습니다.

이 절연체를 **유전체(Dielectric)**라고 합니다.

실제 커패시터에서는 세라믹, 산화막, 플라스틱 필름 등 다양한 재료가 유전체로 사용됩니다.

## 2. 두 판이 연결되어 있지 않은데 어떻게 전기를 저장할까?

커패시터에 전압을 걸어봅시다.

```text
배터리 +

   │
   ↓
██████       |||||        ██████
+ + + +                    - - - -
   │                         │
   └──────── 배터리 ─────────┘
                          -
```

배터리의 양극에 연결된 판에서는 전자가 빠져나가면서 상대적으로 양전하 상태가 됩니다.

반대쪽 판에는 전자가 모이면서 음전하 상태가 됩니다.

중요한 점은 **전자가 절연체를 뚫고 한쪽 판에서 다른 판으로 이동하는 것이 아니라는 것**입니다.

배터리가 외부 회로를 통해 전자를 이동시켜 양쪽 판에 서로 반대되는 전하를 만들어냅니다.

즉 커패시터는 전하를 한쪽에만 쌓아두는 것이 아니라 **양쪽 판에 서로 반대되는 전하를 분리하여 저장합니다.**

## 3. 전기장은 어디에 만들어질까?

한쪽 판은 양전하, 다른 판은 음전하 상태가 되면 두 판 사이에 전기장이 만들어집니다.

```text
+ + + + + +        - - - - - -

██████████          ██████████
      → → → → → →
       전기장
```

커패시터에 저장되는 에너지는 단순히 전자가 금속판 위에 쌓여 있는 형태만으로 생각하기보다 **두 판 사이에 만들어진 전기장에 저장된다**고 이해하는 것이 더 정확합니다.

저장 에너지는 다음과 같이 표현할 수 있습니다.

**E = 1/2 × C × V²**

* E: 저장 에너지, J
* C: 정전용량, F
* V: 커패시터 양단 전압, V

전압이 두 배가 되면 저장 에너지는 네 배가 됩니다.

## 4. 정전용량 C는 무엇일까?

커패시터가 얼마나 많은 전하를 저장할 수 있는지를 나타내는 값이 **정전용량(Capacitance)**입니다.

기호는 C를 사용하고 단위는 패럿(F)입니다.

기본 관계는 다음과 같습니다.

**Q = C × V**

* Q: 저장된 전하량, C
* C: 정전용량, F
* V: 커패시터 양단 전압, V

식의 의미는 간단합니다.

같은 전압에서 정전용량이 큰 커패시터일수록 더 많은 전하를 저장할 수 있습니다.

예를 들어 1F 커패시터에 1V를 걸면 이상적으로 1C의 전하가 저장됩니다.

**1 F = 1 C/V**

입니다.

## 5. 실제로는 F보다 작은 단위를 많이 사용한다

1F은 일반적인 전자회로에서는 매우 큰 정전용량입니다.

그래서 보통 다음과 같은 작은 단위를 사용합니다.

| 단위  |              크기 |
| --- | --------------: |
| 1F  |              1F |
| 1mF |          0.001F |
| 1μF |       0.000001F |
| 1nF |    0.000000001F |
| 1pF | 0.000000000001F |

즉,

**1μF = 1,000nF**

**1nF = 1,000pF**

입니다.

전자회로에서는 몇 pF에서 수천 μF까지 매우 다양한 값이 사용됩니다.

## 6. 무엇이 정전용량을 결정할까?

평행한 두 금속판으로 만든 이상적인 커패시터에서는 정전용량을 다음과 같이 생각할 수 있습니다.

**C = ε × A / d**

* C: 정전용량
* ε: 유전체의 특성
* A: 서로 마주 보는 판의 면적
* d: 판 사이 거리

즉,

* 판의 면적이 넓을수록 C 증가
* 판 사이가 가까울수록 C 증가
* 유전체 특성에 따라 C 변화

합니다.

```text
면적 증가

████████████
||||||||||||
████████████

→ 정전용량 증가


간격 감소

████████████
   |||
████████████

→ 정전용량 증가
```

실제 커패시터는 작은 부피에서 큰 면적을 확보하기 위해 얇은 층을 여러 겹 쌓거나 말아서 만듭니다.

## 7. 커패시터를 배터리에 연결하면 처음에는 전류가 흐른다

빈 커패시터를 배터리에 연결해봅시다.

```text
+V ───── [ 커패시터 ] ───── GND
```

연결 직후 커패시터 양단 전압은 아직 거의 0V입니다.

배터리와 커패시터 사이에 큰 전압 차이가 있기 때문에 전하가 빠르게 이동합니다.

즉 **충전 전류가 흐릅니다.**

```text
연결 직후

전류 큼
  ↓↓↓

+V ───────── || ───────── GND
```

전하가 쌓일수록 커패시터 전압이 올라갑니다.

그러면 배터리와 커패시터 사이의 전압 차이가 줄어들어 충전 전류도 점점 감소합니다.

## 8. 충전이 끝나면 왜 전류가 멈출까?

충분한 시간이 지나 커패시터 전압이 전원 전압과 같아졌다고 생각해봅시다.

```text
전원 = 5V
커패시터 = 5V
```

더 이상 커패시터를 충전시킬 전압 차이가 없습니다.

따라서 이상적인 커패시터에서는 전류가 0에 가까워집니다.

```text
충전 시작

전류 ██████████


시간 경과

전류 ██████


더 경과

전류 ██


충전 완료

전류 ≈ 0
```

그래서 이상적인 커패시터는 **직류가 충분히 오래 유지되면 개방 회로처럼 동작한다**고 설명합니다.

## 9. 그렇다면 커패시터는 직류를 차단하는 부품인가?

많이 사용하는 표현이지만 조금 조심해서 이해해야 합니다.

커패시터를 직류 전원에 연결하면 **처음에는 충전 전류가 흐릅니다.**

충전이 완료되고 전압이 변하지 않는 정상 상태가 되면 이상적으로 전류가 흐르지 않습니다.

따라서

> 커패시터에는 직류가 절대 흐르지 않는다.

보다는

> 일정한 직류 상태에서는 충전이 끝난 후 전류가 거의 흐르지 않는다.

라고 이해하는 것이 정확합니다.

## 10. 커패시터를 전원에서 떼도 전압이 남아 있을 수 있다

충전된 커패시터를 전원에서 분리해봅시다.

```text
     + + + +
     ██████
      ||||
     ██████
     - - - -
```

전하가 빠져나갈 경로가 없다면 이상적으로는 충전 상태를 유지합니다.

즉 커패시터 양단에 전압이 남습니다.

실제 커패시터에는 누설 전류가 있기 때문에 시간이 지나면 천천히 방전됩니다.

하지만 큰 커패시터나 높은 전압을 사용하는 회로에서는 전원을 끈 뒤에도 위험한 전압이 상당 시간 남을 수 있습니다.

그래서 전원 장치 내부의 대용량 커패시터를 다룰 때는 주의해야 합니다.

## 11. 커패시터를 저항에 연결하면 방전된다

충전된 커패시터에 저항을 연결하면 전하가 저항을 통해 이동합니다.

```text
       ┌──[ 저항 ]──┐
       │             │
       └──── || ─────┘
          커패시터
```

처음에는 전압이 높으므로 전류가 많이 흐릅니다.

방전되면서 전압이 낮아지고 전류도 점점 감소합니다.

```text
커패시터 전압

높음 ██████████
       ███████
        █████
          ██
           ▏
낮음 ─────────────→ 시간
```

커패시터는 일반적인 배터리처럼 일정한 전압을 오랫동안 유지하며 방전되는 것이 아니라, 방전할수록 전압이 계속 떨어집니다.

## 12. 전압은 순간적으로 변할 수 없다

이상적인 커패시터의 중요한 성질입니다.

커패시터에서 전류와 전압의 관계는 다음과 같습니다.

**I = C × dV/dt**

수학적으로 조금 어려워 보이지만 뜻은 간단합니다.

**전압을 빠르게 바꾸려면 큰 전류가 필요하다**는 뜻입니다.

식의 형태를 바꾸면,

**dV/dt = I / C**

입니다.

같은 전류라면 정전용량 C가 클수록 전압 변화가 느립니다.

즉 큰 커패시터는 전압이 빠르게 변하는 것을 더 강하게 억제합니다.

## 13. 왜 전압이 순간적으로 바뀔 수 없을까?

예를 들어 커패시터 전압을 0V에서 5V로 정확히 0초 만에 올리려고 한다고 생각해봅시다.

`dV/dt`가 무한대가 됩니다.

그러면

**I = C × dV/dt**

에서 필요한 전류 역시 무한대가 됩니다.

실제 회로에서는 무한대의 전류를 만들 수 없습니다.

따라서 커패시터 전압은 현실적으로 일정한 시간을 두고 변합니다.

이 특성이 전원 안정화와 필터링에 매우 중요합니다.

## 14. 저항과 커패시터를 함께 연결하면?

저항과 커패시터를 함께 사용한 회로를 **RC 회로**라고 합니다.

가장 기본적인 충전 회로는 다음과 같습니다.

```text
+5V ──[ R ]──┬── 출력
             │
            [ C ]
             │
            GND
```

전원을 처음 켜면 커패시터는 충전되지 않은 상태입니다.

출력 전압은 0V 부근에서 시작합니다.

시간이 지나면서 저항을 통해 커패시터가 충전되고 출력 전압이 점점 5V에 가까워집니다.

```text
전압
5V│              ─────────
  │           __
  │        __
  │      _/
  │    _/
0V└────────────────────→ 시간
```

전압은 직선으로 올라가지 않고 곡선 형태로 증가합니다.

## 15. 시정수 τ는 무엇일까?

RC 회로의 충전과 방전 속도를 결정하는 값이 **시정수(Time Constant)**입니다.

그리스 문자 τ(타우)를 사용하며 다음과 같습니다.

**τ = R × C**

* R: 저항, Ω
* C: 정전용량, F
* τ: 시간, s

예를 들어,

* R = 1kΩ
* C = 1,000μF

라면

```text
R = 1,000Ω
C = 0.001F
```

따라서,

**τ = 1,000 × 0.001 = 1초**

입니다.

## 16. 1τ가 지나면 완전히 충전될까?

아닙니다.

커패시터 충전은 점점 느려지면서 전원 전압에 가까워집니다.

대략적으로,

| 시간 |    충전 전압 |
| -- | -------: |
| 1τ |    약 63% |
| 2τ |    약 86% |
| 3τ |    약 95% |
| 4τ |    약 98% |
| 5τ | 약 99% 이상 |

정도입니다.

그래서 실무에서는 보통 **5τ 정도가 지나면 거의 충전 완료**라고 생각하기도 합니다.

## 17. 방전에서도 같은 시정수를 사용한다

충전된 커패시터를 저항을 통해 방전하면 전압은 다음과 같이 감소합니다.

```text
전압
5V│████
  │   ███
  │      ██
  │        ██
  │          █
0V└──────────────────→ 시간
```

대략,

| 시간 |   남은 전압 |
| -- | ------: |
| 1τ |   약 37% |
| 2τ |   약 14% |
| 3τ |    약 5% |
| 5τ | 약 1% 이하 |

정도가 됩니다.

이 원리를 이용해 지연회로나 간단한 타이밍 회로를 만들 수 있습니다.

## 18. 커패시터는 왜 교류를 통과시키는 것처럼 보일까?

교류에서는 전압이 계속 변합니다.

```text
전압

 +      +      +
 │     / \    / \
0┼────/───\──/───\────
 │   /     \/     \
 -
```

전압이 계속 변하면 커패시터 역시 계속 충전과 방전을 반복합니다.

따라서 외부 회로에서는 전류가 계속 흐르는 것처럼 보입니다.

하지만 전자가 유전체를 직접 통과하는 것은 아닙니다.

```text
한쪽 판 충전
     ↓
반대쪽 회로에서 전하 이동
     ↓
전압 방향 변경
     ↓
반대 방향 충전
```

이 과정이 반복됩니다.

## 19. 주파수가 높을수록 커패시터를 통해 전류가 더 잘 흐른다

커패시터가 교류를 얼마나 방해하는지를 **용량성 리액턴스(Capacitive Reactance)**라고 합니다.

기호는 `XC`이고 다음과 같습니다.

**XC = 1 / (2πfC)**

* f: 주파수, Hz
* C: 정전용량, F

식을 보면,

* 주파수 f가 높을수록 XC 감소
* 정전용량 C가 클수록 XC 감소

합니다.

즉 **고주파일수록 커패시터는 전류를 더 쉽게 통과시키는 것처럼 동작합니다.**

## 20. 이 특성이 노이즈 제거에 이용된다

전원에 일정한 5V DC가 있다고 생각해봅시다.

그런데 여기에 아주 빠른 노이즈가 섞였습니다.

```text
정상 전압

──────────────


노이즈가 섞임

────┬─┬──┬─┬────
    │ │  │ │
```

전원과 GND 사이에 커패시터를 연결하면 고주파 노이즈 성분은 커패시터를 통해 GND 쪽으로 흐르기 쉬워집니다.

```text
5V ───────────── 회로
        │
       [C]
        │
       GND
```

결과적으로 전원 전압의 빠른 변화를 줄이는 효과를 얻을 수 있습니다.

## 21. 디커플링 커패시터란 무엇일까?

CPU, MCU, 메모리 같은 디지털 IC는 내부 트랜지스터가 빠르게 켜지고 꺼집니다.

그 순간 순간적으로 큰 전류가 필요할 수 있습니다.

```text
IC 동작

평소 ────────
             │
             │ 순간 큰 전류 필요
             ▼
```

전원공급장치가 멀리 있으면 배선과 PCB 패턴의 저항·인덕턴스 때문에 필요한 전류가 즉시 공급되지 못할 수 있습니다.

그러면 IC 근처의 전압이 순간적으로 떨어질 수 있습니다.

그래서 IC 바로 옆에 작은 커패시터를 연결합니다.

```text
전원 ─────────┬── IC
              │
             [C]
              │
             GND
```

이 커패시터가 순간적으로 필요한 전류를 공급하고 전압 변화를 줄여줍니다.

이를 **Decoupling Capacitor**라고 합니다.

## 22. 왜 IC 바로 옆에 붙여야 할까?

같은 커패시터라도 IC에서 멀리 떨어지면 효과가 떨어질 수 있습니다.

PCB 패턴 자체에도 저항과 인덕턴스가 있기 때문입니다.

```text
좋은 배치

IC ── C
      │
     GND


멀리 배치

IC ───────────── C
                 │
                GND
```

빠른 전류 변화에서는 짧은 배선이 중요합니다.

그래서 보통 0.1μF 정도의 세라믹 커패시터를 IC 전원 핀 바로 가까이에 배치하는 모습을 자주 볼 수 있습니다.

정확한 값은 IC 데이터시트를 따라야 합니다.

## 23. Bulk Capacitor는 무엇일까?

작은 세라믹 커패시터가 매우 빠른 고주파 변화를 담당한다면, 더 큰 전류 변화나 낮은 주파수의 전압 흔들림을 보완하기 위해 큰 커패시터를 함께 사용하기도 합니다.

이를 흔히 **Bulk Capacitor**라고 부릅니다.

```text
전원 ──┬──────── 회로
       │
     [1000μF]
       │
      GND
```

대용량 전해 커패시터가 자주 사용됩니다.

실제로는,

```text
전원 ──┬────── IC
       │
    [470μF]
       │
      GND

IC 근처

VCC ──┬── IC
      [0.1μF]
       │
      GND
```

처럼 큰 커패시터와 작은 커패시터를 함께 사용하기도 합니다.

## 24. 왜 크기가 다른 커패시터를 여러 개 사용할까?

이상적인 커패시터라면 큰 용량 하나만 사용해도 될 것처럼 보입니다.

하지만 실제 커패시터에는 여러 비이상적인 성분이 있습니다.

대표적으로,

* ESR
* ESL
* 누설 저항

등이 있습니다.

따라서 커패시터 종류와 크기에 따라 잘 대응하는 주파수 영역이 달라집니다.

그래서 실제 회로에서는,

```text
큰 전해 커패시터
      +
중간 용량
      +
작은 세라믹

→ 넓은 주파수 범위의 전원 안정화
```

처럼 구성하기도 합니다.

## 25. ESR은 무엇일까?

실제 커패시터 내부에는 아주 작은 저항 성분이 존재합니다.

이를 **Equivalent Series Resistance**, 즉 ESR이라고 합니다.

이상적인 커패시터를 실제 커패시터로 표현하면,

```text
──[ ESR ]──||──
          이상적 C
```

처럼 생각할 수 있습니다.

커패시터에 큰 전류가 흐르면 ESR 때문에 열이 발생합니다.

**P = I² × ESR**

이므로 고전류 회로에서는 ESR이 매우 중요합니다.

## 26. 리플 전류는 무엇일까?

전원 회로나 ESC에서는 커패시터가 계속 충전과 방전을 반복합니다.

즉 커패시터 내부로 상당한 교류성 전류가 흐를 수 있습니다.

이를 **Ripple Current**라고 합니다.

```text
충전 → 방전 → 충전 → 방전
  ↑      ↓      ↑      ↓

커패시터 내부에 반복적인 전류
```

리플 전류가 커지면 ESR에 의해 발열이 발생합니다.

따라서 대용량 전해 커패시터를 고를 때는 용량과 전압뿐 아니라 **허용 리플 전류**도 중요합니다.

## 27. ESC에 큰 커패시터가 붙어 있는 이유

RC카 ESC를 보면 배터리 입력 근처에 큰 전해 커패시터가 여러 개 붙어 있는 경우가 많습니다.

```text
배터리
  │
  ├── [대용량 커패시터]
  │
 ESC
  │
모터
```

브러시리스 ESC는 MOSFET을 매우 빠르게 켰다 껐다 합니다.

그 과정에서 배터리에서 요구하는 전류가 빠르게 변합니다.

```text
전류 요구

낮음 ──┐    ┌──
       │    │
높음   └────┘
```

배터리와 ESC 사이의 전선에는 저항과 인덕턴스가 있습니다.

따라서 전류가 갑자기 변하면 ESC 입력 전압도 흔들릴 수 있습니다.

커패시터는 이 순간적인 변화에 빠르게 반응합니다.

## 28. ESC에서 커패시터는 순간적으로 전류를 공급한다

모터가 순간적으로 큰 전류를 요구할 때 ESC 근처의 커패시터가 일부 전류를 공급할 수 있습니다.

```text
배터리 ────────────┐
                    ├── ESC
커패시터 ──────────┘
       ↑
 순간적인 전류 보조
```

반대로 회로에서 순간적으로 에너지가 되돌아오거나 전압이 올라가려 할 때 커패시터가 전하를 받아들여 전압 상승을 완화합니다.

즉 ESC의 입력 커패시터는 단순히 "전기를 많이 저장하는 통"이라기보다 **전압이 빠르게 출렁이는 것을 억제하는 완충 장치**에 가깝습니다.

## 29. 배터리가 있는데 왜 커패시터가 또 필요할까?

배터리도 전류를 공급할 수 있습니다.

하지만 배터리는 ESC에서 수 cm 또는 수십 cm 떨어져 있고 그 사이에는 전선과 커넥터가 있습니다.

```text
배터리 ───── 긴 전선 ───── ESC
```

전선에는 저항뿐 아니라 인덕턴스가 있습니다.

특히 매우 빠른 전류 변화에서는 인덕턴스의 영향 때문에 배터리가 순간적인 전류 변화에 바로 대응하지 못할 수 있습니다.

그래서 커패시터를 MOSFET 가까이에 배치합니다.

```text
배터리 ─────────────── ESC
                     │
                  [커패시터]
                     │
                    GND
```

짧은 경로에서 빠르게 전류를 공급하고 흡수할 수 있기 때문입니다.

## 30. ESC의 커패시터가 고장 나면 어떤 일이 생길까?

입력 커패시터의 성능이 떨어지면 전원 전압의 리플과 스파이크가 커질 수 있습니다.

그 결과,

* MOSFET 스트레스 증가
* ESC 발열 증가
* 불안정한 동작
* 전원 노이즈 증가

등이 발생할 수 있습니다.

특히 오래된 전해 커패시터는 내부 전해액의 열화로 용량이 줄거나 ESR이 증가할 수 있습니다.

겉으로 멀쩡해 보여도 성능이 떨어질 수 있습니다.

## 31. 전해 커패시터는 극성이 있다

대용량 회로에서 많이 사용하는 **알루미늄 전해 커패시터**는 대부분 극성이 있습니다.

```text
       +
       │
     [ C ]
       │
       -
```

부품 몸체에 보통 음극 쪽 표시가 있습니다.

극성을 반대로 연결하면 커패시터가 손상될 수 있으며 심한 경우 내부 압력이 올라가 파열될 수도 있습니다.

따라서 반드시 극성을 확인해야 합니다.

## 32. 커패시터의 전압 정격도 중요하다

커패시터에는 최대 사용 전압이 있습니다.

예를 들어,

**1000μF 16V**

라고 표시되어 있다면,

* 정전용량: 1000μF
* 전압 정격: 16V

를 의미합니다.

12V 회로라고 해서 항상 16V 커패시터가 충분하다고 단순하게 결정할 수는 없습니다.

전원 변동과 스파이크, 온도, 수명 등을 고려해 적절한 전압 여유를 둡니다.

정격을 초과하면 유전체가 손상되어 누설 전류 증가나 파괴로 이어질 수 있습니다.

## 33. 세라믹 커패시터는 무엇이 다를까?

세라믹 커패시터는 유전체로 세라믹 재료를 사용하는 커패시터입니다.

대표적인 특징은,

* 작음
* 극성이 없음
* 낮은 ESR과 ESL
* 고주파 특성이 좋음

등입니다.

그래서 IC의 디커플링 용도로 매우 많이 사용됩니다.

```text
VCC ──┬── IC
      │
    [0.1μF 세라믹]
      │
     GND
```

다만 세라믹 커패시터는 종류에 따라 실제 인가 전압이나 온도에 의해 정전용량이 크게 변할 수 있습니다.

## 34. 전해 커패시터의 장점은 큰 용량이다

알루미늄 전해 커패시터는 같은 크기의 세라믹이나 필름과 비교해 큰 정전용량을 비교적 저렴하게 만들 수 있습니다.

예를 들어,

* 470μF
* 1,000μF
* 2,200μF

등의 대용량이 흔합니다.

그래서,

* 전원 평활
* Bulk Capacitor
* ESC 입력부
* 오디오 전원

등에 많이 사용됩니다.

단점으로는,

* 극성이 있음
* ESR이 상대적으로 큼
* 수명이 있음
* 온도에 민감함

등이 있습니다.

## 35. 필름 커패시터는 어디에 사용할까?

필름 커패시터는 얇은 플라스틱 필름을 유전체로 사용합니다.

대표적인 특징은,

* 안정적인 특성
* 낮은 손실
* 비교적 높은 전압 대응
* 좋은 펄스 특성

등입니다.

그래서,

* 오디오 회로
* 스너버 회로
* 고전압 회로
* 모터 회로
* AC 회로

등에서 사용됩니다.

크기와 가격 때문에 모든 회로에서 세라믹이나 전해를 대신하지는 않습니다.

## 36. 커패시터 종류를 간단히 비교하면

| 종류      | 특징              | 대표 용도        |
| ------- | --------------- | ------------ |
| 세라믹     | 작고 빠름, 저ESR     | IC 디커플링, 고주파 |
| 알루미늄 전해 | 큰 용량, 저렴        | 전원 평활, Bulk  |
| 필름      | 안정적, 펄스 특성 우수   | AC, 스너버, 오디오 |
| 탄탈      | 비교적 큰 용량과 작은 크기 | 전원 회로        |
| 슈퍼커패시터  | 매우 큰 정전용량       | 에너지 저장, 백업   |

각 커패시터는 단순히 정전용량 숫자만 다른 것이 아니라 주파수 특성, ESR, 수명, 전압 특성 등이 다릅니다.

## 37. 커패시터를 병렬로 연결하면?

커패시터를 병렬로 연결하면 정전용량은 더해집니다.

**C전체 = C1 + C2 + C3 + …**

예를 들어,

* 100μF
* 220μF

를 병렬 연결하면,

**C전체 = 320μF**

입니다.

```text
     ┌──|| 100μF──┐
─────┤            ├─────
     └──|| 220μF──┘
```

전원 회로에서 여러 커패시터를 병렬로 사용하는 것을 자주 볼 수 있습니다.

## 38. 커패시터를 직렬로 연결하면?

직렬 연결에서는 저항과 반대로 전체 정전용량이 작아집니다.

**1 / C전체 = 1 / C1 + 1 / C2 + …**

두 개라면,

**C전체 = C1 × C2 / (C1 + C2)**

입니다.

같은 값 C 두 개를 직렬로 연결하면 전체 정전용량은 C/2가 됩니다.

예를 들어 100μF 두 개를 직렬로 연결하면 이상적으로 50μF입니다.

## 39. 커패시터는 필터를 만드는 데 사용할 수 있다

저항과 커패시터를 조합하면 특정 주파수의 신호를 줄이거나 통과시키는 필터를 만들 수 있습니다.

예를 들어 다음 회로는 간단한 **RC Low-Pass Filter**입니다.

```text
입력 ──[ R ]──┬── 출력
              │
             [ C ]
              │
             GND
```

낮은 주파수 신호는 출력으로 비교적 잘 전달됩니다.

높은 주파수 성분은 커패시터를 통해 GND 쪽으로 빠져나가기 쉽습니다.

따라서 고주파 노이즈를 줄이는 데 사용할 수 있습니다.

## 40. 커패시터를 신호 경로에 직렬로 넣기도 한다

다음처럼 커패시터를 신호와 직렬로 연결할 수도 있습니다.

```text
입력 ──||──── 출력
```

일정한 DC 성분은 시간이 지나면 통과하지 못하지만 변화하는 AC 성분은 전달될 수 있습니다.

이를 **AC Coupling** 또는 커플링 커패시터라고 합니다.

오디오 회로에서 DC 전압을 차단하면서 음성 신호만 다음 단계로 전달하는 데 사용할 수 있습니다.

## 41. 커패시터와 인덕터는 서로 반대처럼 보이는 성질이 있다

커패시터는 **전압이 갑자기 변하려는 것을 방해**합니다.

반대로 인덕터는 **전류가 갑자기 변하려는 것을 방해**합니다.

```text
커패시터

전압 변화 싫어함


인덕터

전류 변화 싫어함
```

이 두 부품을 함께 이해하면 전원회로와 모터 회로를 훨씬 쉽게 이해할 수 있습니다.

ESC에서 MOSFET이 모터의 코일을 빠르게 스위칭할 때 전압과 전류가 복잡하게 움직이는 것도 이 두 성질과 깊은 관련이 있습니다.

## 자주 헷갈리는 내용을 정리하면

| 오해                          | 바르게 이해하기                           |
| --------------------------- | ---------------------------------- |
| 커패시터 안에 전자가 한가득 저장된다        | 두 판에 반대 전하가 분리되고 전기장에 에너지가 저장됨     |
| 전자가 절연체를 통과한다               | 정상 동작에서는 두 판 사이 유전체를 직접 통과하지 않음    |
| 커패시터에는 직류가 전혀 흐르지 않는다       | 충전·방전 중에는 전류가 흐르고 정상 DC 상태에서 거의 멈춤 |
| 충전된 커패시터는 전압이 바로 사라진다       | 방전 경로가 없으면 전압이 일정 시간 남을 수 있음       |
| 큰 용량일수록 항상 좋다               | 용도에 따라 ESR, ESL, 주파수 특성도 중요함       |
| 커패시터는 모두 극성이 있다             | 전해 등 일부 종류만 극성이 있음                 |
| 정격 16V면 16V까지 무조건 안전하다      | 스파이크, 온도, 수명 등을 고려해 여유를 둬야 함       |
| 대용량 커패시터 하나면 작은 커패시터가 필요 없다 | 주파수 특성이 달라 여러 종류를 함께 사용하기도 함       |
| ESC의 커패시터는 배터리 용량을 늘리는 역할이다 | 주된 역할은 빠른 전압·전류 변화를 완화하는 것         |
| 커패시터의 실제 용량은 항상 표시값과 같다     | 공차, 온도, 전압 등에 따라 달라질 수 있음          |

## 핵심만 다시 정리하면

커패시터는 **두 도체 사이에 전하를 분리하고 전기장 형태로 에너지를 저장하는 부품**입니다.

핵심 관계는 다음과 같습니다.

**Q = C × V**

그리고 커패시터의 전류는 전압이 얼마나 빠르게 변하는지와 관계가 있습니다.

**I = C × dV/dt**

이 식 때문에 커패시터는 전압의 급격한 변화를 완화합니다.

```text
전압 급변
   ↓
커패시터에 큰 충·방전 전류
   ↓
전압 변화 완화
```

저항과 함께 사용하면 충전과 방전 속도는

**τ = R × C**

라는 시정수로 결정됩니다.

또 주파수가 높은 신호일수록 커패시터를 통해 더 쉽게 전류가 흐르는 것처럼 동작하기 때문에 전원 노이즈 제거와 필터링에도 사용할 수 있습니다.

실제 전자회로에서는,

```text
작은 세라믹 커패시터
        ↓
빠른 고주파 노이즈 대응


대용량 전해 커패시터
        ↓
큰 전류 변화와 저주파 전압 변동 대응
```

처럼 서로 다른 종류를 함께 사용하기도 합니다.

RC카 ESC의 입력부에 대용량 커패시터가 붙어 있는 이유도 같습니다.

MOSFET이 모터 전류를 빠르게 스위칭하면서 발생하는 순간적인 전류 변화와 전압 스파이크를 커패시터가 가까운 위치에서 흡수하고 공급합니다.

결국 커패시터는 단순히 **전기를 잠깐 저장하는 부품**이라기보다,

**전압 변화를 완화하고 필요한 순간에 빠르게 전하를 주고받는 부품**

이라고 이해하는 것이 실제 회로의 동작에 더 가깝습니다.

다음으로 **인덕터**까지 이해하면 커패시터와 정반대 성질이 어떻게 전원회로, DC-DC 컨버터, 모터, ESC에서 함께 사용되는지 연결해서 볼 수 있습니다.
